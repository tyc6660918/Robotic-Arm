================================================================================
              RST 夹取端三电机独立控制设计方案
================================================================================
文档版本: V2.0 (简化版)
日期:     2026-08-02
适用:     RST 手术器械夹取端 (俯仰 + 上夹 + 下夹)
主控:     STM32F103ZET6 (72MHz)
电机:     MG310L 直流电机 × 3 (GMR 磁增量编码器, 1:50 减速)
驱动:     TB6612 直流电机驱动器 × 2 (双通道)
================================================================================


一、系统概述
================================================================================

1.1 设计目标
--------------------------------------------------------------------------------
三个自由度，三台电机，每台电机独立位置控制:

    自由度 1: 俯仰 (Pitch)      —— 头部上下摆动
    自由度 2: 上夹爪 (Upper Jaw) —— 独立开合
    自由度 3: 下夹爪 (Lower Jaw) —— 独立开合

1.2 核心需求
--------------------------------------------------------------------------------
(1) 实时流式: PC 以 50~100Hz 持续下发三路目标角度，控制板实时跟随
(2) 位置精度: ±1° (编码器 0.15° 分辨率，满足)
(3) 夹持牢固: 由减速比 + 电流限幅保证，堵转时维持恒定力矩
(4) 简单直接: 无复杂模式切换，三路位置指令各管各的

1.3 设计原则
--------------------------------------------------------------------------------
(1) 三电机完全独立: 各有一个位置环 + 电流限幅，互不干扰
(2) 电流限幅是唯一安全底线: 任何模式不可绕过
(3) 上位机只发"目标角度"，其余由控制板自动完成


二、硬件组成与接线
================================================================================

2.1 引脚分配
--------------------------------------------------------------------------------
    PWM 输出:
        PA8  (TIM1_CH1)  → Pitch 电机     (TB6612#1 通道A)
        PC6  (TIM8_CH1)  → 上夹电机       (TB6612#1 通道B)
        PC7  (TIM8_CH2)  → 下夹电机       (TB6612#2 通道A)

    方向控制 (GPIO):
        PB0/PB1   → Pitch 电机 IN1/IN2
        PB5/PB12  → 上夹电机 IN1/IN2
        PB13/PB14 → 下夹电机 IN1/IN2

    编码器输入 (定时器编码器模式):
        PA6/PA7  (TIM3)  → Pitch 编码器 A/B
        PB6/PB7  (TIM4)  → 上夹编码器 A/B
        PA15/PB3 (TIM2)  → 下夹编码器 A/B  (32位定时器)

    电流采样 (ADC1):
        PA4  → Pitch 电机电流
        PA5  → 上夹电机电流
        PA3  → 下夹电机电流

    状态指示:
        PE2  → Pitch 状态 LED
        PE3  → 上夹状态 LED
        PE4  → 下夹状态 LED
        PE5  → 系统心跳 LED

2.2 电机与编码器接线 (6端子)
--------------------------------------------------------------------------------
        M+      → 驱动器 OUT1 (TB6612)
        M-      → 驱动器 OUT2 (TB6612)
        ENC VCC → 3.3V (编码器供电)
        ENC GND → GND
        ENC A   → 定时器 CH1 引脚
        ENC B   → 定时器 CH2 引脚

    注意:
    (1) 编码器电源与电机电源完全隔离
    (2) A/B 信号线远离电机电源线, 使用双绞线
    (3) 磁铁固定在电机后轴, 与芯片距离 <1mm


三、GMR 编码器原理与使用
================================================================================

3.1 工作原理
--------------------------------------------------------------------------------
    GMR (巨磁阻) 编码器:

        电机后轴磁铁旋转 → 芯片检测磁场方向
        → 输出 A/B 两路正交方波 (相位差 90°)
        → 定时器编码器模式自动解码方向与计数

    特性:
        - 增量式编码器 (上电无绝对位置, 需标定)
        - A 超前 B = 正转; B 超前 A = 反转
        - 12 线 × 4 倍频 × 50 减速 = 2400 counts/输出轴转
        - 分辨率: 360° / 2400 = 0.15°/count

3.2 读取方式
--------------------------------------------------------------------------------
    定时器编码器模式 (TI1 + TI2):

        硬件自动加减计数, 无需软件判断方向
        周期读取 CNT:

            角度 = CNT × 360° / 2400
            速度 = (CNT_now - CNT_prev) / Δt

3.3 注意事项
--------------------------------------------------------------------------------
    (1) 磁铁居中, 距芯片 <1mm
    (2) A/B 相位必须 90° (示波器验证)
    (3) 信号线远离电源线
    (4) 每次上电必须标定


四、控制架构 (核心)
================================================================================

4.1 控制结构
--------------------------------------------------------------------------------
    每台电机独立一套, 三层结构:

    ┌────────────────────────────────────────────┐
    │  位置环 (1kHz)                              │
    │                                             │
    │  目标角度 ──→ [位置PID] ──→ 速度目标        │
    │                ↑                           │
    │  编码器角度 ←── CNT 读取                    │
    └──────────────────────┬─────────────────────┘
                           │
    ┌──────────────────────▼─────────────────────┐
    │  速度环 (5kHz)                              │
    │                                             │
    │  速度目标 ──→ [速度PI] ──→ PWM 占空比       │
    │                ↑                           │
    │  编码器差分 ←── 速度计算                    │
    └──────────────────────┬─────────────────────┘
                           │
    ┌──────────────────────▼─────────────────────┐
    │  电流限幅 (20kHz)                           │
    │                                             │
    │  ADC电流 ──→ 超 I_max? ──→ 钳位 PWM        │
    │                                             │
    │  I_max 固定: 正常 1.0A, 标定 0.3A           │
    └────────────────────────────────────────────┘

4.2 各层作用
--------------------------------------------------------------------------------
    位置环: 决定精度, 输出速度目标 (不是直接 PWM)
    速度环: 决定平滑度, 抑制超调, 碰物体时自然减速
    电流限幅: 安全底线 + 夹持力上限 (堵转时电流 = 夹持力)

4.3 控制参数
--------------------------------------------------------------------------------
    (1) 位置环 (每电机独立):
            Kp: 位置比例增益 (响应速度)
            Ki: 积分增益 (消除稳态误差, 带限幅)
            输出限幅: ±最大速度

    (2) 速度环 (每电机独立):
            Kp: 速度比例增益
            Ki: 速度积分增益
            输出限幅: ±1000 (PWM 满量程)

    (3) 电流限幅:
            正常运行: 1.0A
            标定模式: 0.3A

    三个电机框架相同, 参数独立存储 (EEPROM), 上电自动加载。
    俯仰电机负载大, Kp 适中; 夹爪电机负载小, Kp 可稍高。


五、夹爪控制 (简化)
================================================================================

5.1 控制方式
--------------------------------------------------------------------------------
    上夹和下夹就是两个独立的位置控制通道:

        上位机 ──→ 上夹目标角度 ──→ 上夹位置环 ──→ 上夹电机
        上位机 ──→ 下夹目标角度 ──→ 下夹位置环 ──→ 下夹电机

    没有模式切换, 没有同步/独立之分。
    上位机想要什么动作, 直接发对应的两个角度即可:

        同步开合:   上夹 30°, 下夹 30°  (同时发)
        单爪动作:   上夹 15°, 下夹保持
        夹持物体:   上夹 0°, 下夹 0°   (全闭, 电流限幅兜底)

5.2 夹持牢固原理
--------------------------------------------------------------------------------
    夹持力 = 电机电流 × 转矩常数 × 减速比 (1:50)

    当目标角度是"闭合"而物体挡住时:
        电机堵转 → 电流上升到限幅值 1.0A
        → PWM 被钳位 → 电机维持恒定力矩

    牢固性由三点保证:
    (1) 1:50 减速比 → 大力矩放大
    (2) 电流限幅 → 恒定力矩输出, 不随位置衰减
    (3) 夹爪接触面齿纹/硅胶 → 摩擦防滑

    如果 1.0A 夹持力不够, 调高限幅值即可 (最大 2.0A, 需散热评估)。


六、俯仰控制
================================================================================

6.1 控制方式
--------------------------------------------------------------------------------
    与夹爪完全相同的控制框架 (位置环 + 速度环 + 电流限幅):

        上位机 ──→ 俯仰目标角度 ──→ 俯仰位置环 ──→ 俯仰电机

    精度 ±1°, 跟随延迟 < 50ms。

6.2 与夹爪的协同
--------------------------------------------------------------------------------
    三路指令并行执行, 无先后依赖:

        帧1: 俯仰=128, 上夹=60, 下夹=60   (对准 + 张开)
        帧2: 俯仰=120, 上夹=30, 下夹=30   (靠近 + 半闭)
        帧3: 俯仰=115, 上夹=0,  下夹=0    (到位 + 闭合夹持)


七、实时通信协议
================================================================================

7.1 通信方式
--------------------------------------------------------------------------------
    USART1, 115200bps, 8N1
    PC → 控制板: 三路目标角度, 50~100Hz

7.2 指令帧 (PC → 控制板)
--------------------------------------------------------------------------------
    ASCII 文本, \n 结尾:

        P<0-255>U<0-255>L<0-255>\n

        示例: P128U60L60\n

        P = 俯仰目标 (0=一端, 255=另一端)
        U = 上夹目标 (0=全闭, 255=全开)
        L = 下夹目标 (0=全闭, 255=全开)

    最新帧覆盖旧帧, 只执行最新目标。

7.3 状态帧 (控制板 → PC)
--------------------------------------------------------------------------------
        A<P> A<U> A<L> S<状态>\n

        示例: A128 A60 A60 S0\n

        A = 三电机当前角度 (0~255)
        S = 状态码 (0=正常, 1=堵转, 2=过流, 3=未标定)

7.4 控制命令 (低频)
--------------------------------------------------------------------------------
        CALIB\n     → 标定
        STOP\n      → 急停 (三电机失能)
        ENABLE\n    → 使能
        DISABLE\n   → 失能
        PING\n      → 探活 (回复 PONG)


八、上电标定
================================================================================

8.1 流程 (每次上电自动, 约 2~3 秒)
--------------------------------------------------------------------------------
    1. 三电机同时慢速向闭合方向转动 (5% PWM, 限流 0.3A)
    2. 电流突增 = 到限位 → 停 → 记当前位置为 0° (全闭/一端)
    3. 反向慢速到另一端限位 → 记全开角度
    4. 标定完成, 进入就绪

    失败判定: 10 秒内未找到限位 → 报错 (检查编码器/机械)

8.2 状态指示
--------------------------------------------------------------------------------
    标定中: 对应 LED 慢闪
    完成:   LED 常亮
    失败:   LED 快闪


九、安全设计
================================================================================

9.1 保护机制
--------------------------------------------------------------------------------
    (1) 电流限幅: 每电机独立, 20kHz 检查, 不可绕过
    (2) 堵转检测: 电流超限 500ms → 降为维持电流 (50%), 上报状态
    (3) 通信超时: 500ms 无帧 → 保持当前位置; 2s → 自动停止
    (4) 急停:     STOP / 按键 → 三电机立即失能

9.2 机械安全
--------------------------------------------------------------------------------
    (1) 机械限位挡块 (两端)
    (2) 磁铁机械固定 (防震动移位)


十、调试与验收
================================================================================

10.1 硬件调试
--------------------------------------------------------------------------------
    1. 上电 → 心跳 LED 2Hz 闪烁
    2. 逐个电机低速 PWM 测试 → 方向正确
    3. 编码器读数 → 角度随转动变化, 方向正确
    4. 电流采样校准 (空载 0.1~0.3A)

10.2 闭环调试
--------------------------------------------------------------------------------
    1. 速度环: 固定速度 → 速度稳定无震荡
    2. 位置环: 阶跃 ±30° → 无超调, 到位 <500ms
    3. 三电机联动: 正弦轨迹 → 跟随误差 <3°

10.3 验收标准
--------------------------------------------------------------------------------
    位置精度: ±1° (静态)
    响应时间: 阶跃 90% 到位 < 500ms
    实时性:   指令到动作 < 50ms
    夹持:     堵转电流恒定, 不损坏硬件


十一、关键参数汇总
================================================================================

    编码器:    2400 counts/输出轴转, 0.15°/count
    电流限幅:  正常 1.0A / 标定 0.3A / 最大 2.0A
    控制频率:  位置环 1kHz, 速度环 5kHz, 电流限幅 20kHz
    通信:      115200bps, 指令 50~100Hz
    超时保护:  500ms 保持, 2s 停止
    标定时间:  每次上电 2~3 秒
