# 文档根目录总览

## 一、区域功能定位

文档根目录作为 Robotic-Arm 项目的顶层组织层级，包含项目主入口文件（README.md、LICENSE、技术规格说明）以及结构化的 docs/ 文档体系。该区域于 2026 年 8 月 14 日至 15 日经历了重大重构，由扁平结构迁移至分级目录结构，划分为 docs/getting-started、docs/guides、docs/technical 与 docs/archive 四个子目录。该区域提供项目愿景说明、快速入门引导、调试环境配置说明及详细文档导航功能，同时保留历史交接分析文档作为权威事实依据。

## 六、使用说明

文档根目录作为项目的主要导航层级：

**面向新用户：**
1. 从 E:\Robotic-Arm\项目总览与构建系统说明.md 开始，获取项目概述与快速入门信息
2. 阅读 docs/getting-started/新用户入门指南.md，了解 3 种快速场景（硬件调试/运行仿真/控制机械臂）
3. 使用 docs/INDEX.md 作为导航枢纽，定位特定指南

**面向了解项目真实状态的人员：**
1. 阅读 docs/archive/handover-2026-08-09.md，获取循证分析内容（共 566 行，记录 26 项 P0-P2 缺陷、里程碑状态事实依据）
2. 与 docs/technical/architecture.md 交叉参考，了解系统组件、技术栈、坐标约定
3. 注意项目完整技术文档.txt 成稿于重构之前，包含未经交接文档验证的乐观里程碑声明——应视为期望规格而非当前状态

**面向仿真工作：**
1. 查阅 tools/windows_sim/Windows离线仿真说明.md，获取权威边界条件（无串行、无固件依赖、理想 OpenRST 模型）
2. 注意语义不匹配问题：仿真采用俯仰+偏航+抓取模型，硬件采用俯仰+上钳口+下钳口模型——迁移计划待定

**面向固件开发：**
1. RST夹取端控制设计方案.txt 提供完整的控制设计规格
2. 警告：交接文档确认尽管设计完整，固件实现度约为 0%——预计需投入大量实现工作

**路径参考：**
- 重构后路径：robots/Dummy-Arm/firmware/stm32-control（非 rst-control-fw）、moveit2_ws（非 Moveit_ws-main）
- Git 提交 f2db105、2603308、8244d71 记录了重组过程
