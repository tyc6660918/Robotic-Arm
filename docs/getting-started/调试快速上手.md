# STM32 调试快速上手规程（5 分钟）

**环境状态：** 调试环境已完成配置

---

## 一、硬件连接（3 个步骤）

### 步骤 1：连接调试器至上位机

```
CMSIS-DAP（野火 DAP 小智款）→ USB 线缆 → 个人计算机
```

### 步骤 2：连接调试器至目标开发板

```
DAP 调试器 → SWD 排线 → 开发板 SWD 接口
  - SWDIO（串行数据线）
  - SWCLK（串行时钟线）
  - GND（参考地线）
  - 3V3（可选，用于向目标板供电）
```

### 步骤 3：为开发板供电

```
USB 线缆 → 开发板
或
外部电源 → 开发板电源接口
```

## 三、Visual Studio Code 一键调试

### 方法一：按 F5 快捷键（推荐）

1. 在 Visual Studio Code 编辑器中打开项目目录
2. 按 `F5` 快捷键
3. 从下拉列表中选择对应调试配置（例如 "Debug rst-control (DAP)"）
4. 等待自动执行编译→烧录→启动调试流程

### 方法二：使用调试面板

1. 点击左侧边栏调试图标
2. 从下拉菜单中选择调试配置
3. 点击绿色启动按钮

## 五、常见故障排查

### 问题一：OpenOCD 无法建立连接

排查步骤：
1. 确认 CMSIS-DAP 驱动程序已正确安装
2. 检查 SWD 线缆连接正确性，尤其 GND 接线
3. 确认开发板已接通电源
4. 在 USB 设备管理器中验证 DAP 设备是否已识别

### 问题二：按 F5 后编译失败

排查步骤：确认以下工具链已正确安装：
- arm-none-eabi-gcc 交叉编译工具链
- make 构建工具

### 问题三：烧录成功但程序未启动运行

排查步骤：
1. 检查开发板 BOOT0 跳线帽位置，应接至 GND 侧
2. 执行复位操作后重新连接调试器
3. 查看串行端口输出，波特率配置为 115200

## 六、命令行调试模式（可选）

若不使用 Visual Studio Code 图形界面，可通过命令行手动启动调试会话：

```bash
# 终端 1：启动 OpenOCD 服务
cd debug/openocd-configs
openocd -f cmsis-dap-f103.cfg

# 终端 2：启动 GDB 客户端
cd robots/Dummy-Arm/firmware/stm32-control/control
arm-none-eabi-gdb MDK-ARM/control/control.axf
(gdb) target remote :3333
(gdb) load
(gdb) continue
```
