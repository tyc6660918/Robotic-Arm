# 新用户入门区域总览

## 一、区域功能定位

新用户入门区域为初次接触机械臂项目的开发人员与使用者提供入口级文档。该区域提供三条递进式学习路径：基于场景的导航（本文件）、快速硬件调试（调试快速上手.md）以及完整 STM32 开发工作流（开发工作流程.md）。该区域承担项目总览向实际调试与开发的衔接作用，链接至文档树中的深度指南。

## 六、使用说明

新用户入门区域采用渐进式披露模式：

1. **新用户从 docs/getting-started/新用户入门指南.md 开始**——提供基于场景的导航（"需调试硬件"→调试快速上手.md、"需理解工作流"→开发工作流程.md）

2. **通过调试快速上手.md 快速启动硬件调试**——5 分钟路径，涵盖硬件连接、OpenOCD 测试、首次 GDB 会话。如需深入学习则链接至完整调试技术教程.md

3. **通过开发工作流程.md 获取完整工作流**——端到端 STM32 开发周期，包括 CubeMX 代码生成、构建流程、烧录、调试集成

4. **通过 docs/guides/ 目录进行深度学习**——入门文件中引用的详细主题（硬件连接与配置指南.md 用于连接、完整调试技术教程.md 用于 OpenOCD/GDB 精通、Claude人工智能远程调试指南.md 用于 AI 辅助调试）

文档体系假设采用重构后的路径（robots/、debug/、tools/），但包含需修正的遗留引用。所有指南面向 Windows 开发环境与 Git Bash Shell。
