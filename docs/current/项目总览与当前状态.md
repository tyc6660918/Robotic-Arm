# 项目总览与当前状态

## 1. 项目定位

本项目是低成本主从式机器人训练平台，目标是用 Dummy 六轴机械臂、OpenRST 绳驱器械、U-Arm 主端原型和离线仿真，构建可重复的技能训练与验证环境。

系统由四个主要部分组成：

- **Dummy 从臂**：六轴机械臂，负责末端位姿和关节运动。
- **OpenRST 夹爪**：三自由度绳驱器械，负责末端操作。
- **仿真与上位机**：Windows 离线仿真、控制脚本和可视化工具。
- **ROS2/MoveIt2 集成**：规划、服务和流式控制的实验性集成。

## 2. 当前可确认状态

| 模块 | 当前结论 | 证据边界 |
|---|---|---|
| Windows 仿真 | 可运行并有自动化测试 | 只证明数字模型和安全状态机，不证明实机 |
| Dummy 固件 | 可编译、可烧录、串口基础命令可响应 | 电机闭环、反馈和安全机制仍需硬件验证 |
| OpenRST 固件 | 仅完成板级启动骨架 | PID、协议、限流、堵转和看门狗未完成 |
| ROS2/MoveIt2 | 已有实验性工作区和服务代码 | 构建与实机链路尚未形成验收证据 |
| 主从闭环 | 仿真中可验证，硬件中未打通 | 仿真模型与硬件接口仍有语义差异 |

## 3. 推荐工作顺序

1. 先运行 Windows 仿真，确认运动学、映射、滤波和故障恢复。
2. 阅读 Dummy 机械臂文档，完成固件构建和安全的板级调试。
3. 在没有电机负载的情况下补齐 OpenRST 控制板功能。
4. 再设计串口/CAN/ROS2 的统一接口，并进行硬件在环测试。

## 4. 安全边界

- 编译通过不等于电机控制可用。
- 未确认调试器、目标板和串口身份前，不执行烧录、复位或上电。
- 首次电机测试必须断开负载、使用限流电源，并保留物理断电手段。
- 设计目标、仿真结果和真实硬件证据必须分开记录。
