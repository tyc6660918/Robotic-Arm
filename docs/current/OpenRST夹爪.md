# OpenRST 夹爪

## 1. 目标与组成

OpenRST 是 Dummy 末端的三自由度绳驱器械，目标关节为俯仰、左钳口和右钳口。区域包括机械 CAD、URDF、STM32F103 控制板、独立电机驱动和后续的 Dummy/ROS2 集成。

## 2. 设计与实现的差距

已完成或已有资料：

- 控制板和三路电机接口设计。
- OpenRST URDF 和机械模型。
- 基于理想模型的仿真映射。
- `P<pitch>U<upper>L<lower>` 串口协议设计稿。

尚未形成可验收实现：

- 位置/速度/电流级联 PID。
- PWM、编码器和 ADC 电流采样闭环。
- 协议解析、超时和错误处理。
- 限流、堵转检测、看门狗和急停。
- 绳索张紧、归零、机械装配和干涉验证。

## 3. 当前固件判断

`robots/dummy-arm/firmware/stm32-control/` 的固件目前只能作为板级启动骨架。编译成功或串口 `help` 有回应，不能证明电机输出、编码器反馈或安全保护有效。

## 4. 仿真接口边界

Windows 仿真使用简化的 `pitch/yaw/grasp` 模型；硬件 URDF 使用 `pitch/finger_left/finger_right`。两者在钳口语义上不一致，因此仿真通过不等于硬件协议和机构通过。绳索拉伸、摩擦、回差和电机动力学也未在仿真中建模。

## 5. 实施顺序

1. 完成 STM32 控制循环、驱动输出和反馈采样。
2. 固化协议、限位、超时和故障状态机。
3. 完成单关节、低速、无负载测试。
4. 记录绳索张紧和标定数据。
5. 再接入 Dummy 和 ROS2，验证端到端延迟与安全停机。
