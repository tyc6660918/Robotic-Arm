# Dummy 机械臂

## 1. 系统组成

Dummy 区域包含六轴机械臂本体、参考控制器、35/42 系列电机固件、STM32 控制板、ROS2/MoveIt2 工作区和上位机接口。当前最重要的板级固件位于 `robots/dummy-arm/firmware/stm32-control/`。

## 2. 固件状态

STM32F103 控制工程目前是可编译、可烧录、串口控制台可响应的功能骨架。已检查的基础模块包括 GPIO、USART、定时器、ADC、CAN、PWM/编码器接口和调试控制台；不能据此宣称电机闭环已经可用。

关键未完成项：

- 控制循环与 PWM/编码器实际运行验证。
- 电流采样、限流、堵转检测、指令超时和看门狗。
- 串口/CAN 协议与反馈链路的端到端验证。
- 真实探针、目标板和串口设备身份记录。

## 3. 构建与调试

STM32 工程使用 Keil/MDK 工程文件，构建入口为：

`robots/dummy-arm/firmware/stm32-control/control/MDK-ARM/control.uvprojx`

调试配置和 OpenOCD 配置位于 `debug/`。使用前先确认硬件连接和调试器型号，再运行连接测试；任何烧录、复位和电机动作都必须由安全流程明确授权。

## 4. 机械臂控制链路

设计链路为：上位机或 ROS2 发送目标 → Dummy 控制器接收关节/笛卡尔命令 → 控制循环驱动电机 → 编码器反馈回到控制器。当前仓库同时存在串口、CAN 和 ROS2 实验接口，尚未完成统一协议和反馈时序的验收。

## 5. MoveIt2 状态

`robots/dummy-arm/moveit2_ws/` 包含 MoveIt2 配置、服务和流式控制实验。它可作为集成参考，但不能替代硬件控制器验收。构建依赖 ROS2/colcon，运行状态需以当前环境和实际服务代码为准。

## 6. 使用原则

- 先仿真，再无负载板级测试，最后才进入电机测试。
- 将“代码存在”“工程可编译”“串口有响应”“电机闭环通过”视为四个不同等级。
- 历史修复报告只用于追溯，当前状态以代码审阅和最新验证记录为准。
