# 仿真与调试验证

## 1. Windows 离线仿真

入口位于 `tools/windows_sim/run_sim.py`。仿真使用 Python、NumPy、SciPy、Matplotlib 和标准库，不连接串口、不发送电机命令，也不依赖 ROS2。

可验证内容：

- Dummy 正/逆运动学与 Jacobian。
- 主从相对 SE(3) 映射、滤波和速度/加速度限制。
- Deadman、Clutch、HOLD、FAULT 和重新使能逻辑。
- 延迟、掉包、反馈冻结、关节卡死和不可达目标等故障注入。
- CSV/JSON 记录和统计报告。

常用命令（在仓库根目录执行）：

```powershell
python tools\windows_sim\run_sim.py
python tools\windows_sim\run_sim.py --headless --duration 10 --scenario tools\windows_sim\scenarios\circle.json
python -m unittest discover -s tools\windows_sim\tests -v
```

仿真不能证明实机机械精度、串口闭环、绳驱性能、ROS2 QoS 或实时性。

## 2. 调试工具

当前调试配置集中在 `debug/`，包括 OpenOCD 配置、VSCode/Cortex-Debug 配置、连接测试脚本和 AI 辅助诊断说明。调试顺序应为：确认设备身份 → 连接测试 → 编译 → 无负载调试 → 记录证据。

## 3. 上位机与接口

仓库包含串口命令行工具、可视化工具、HTTP/ROS2 实验服务和 Windows 仿真。它们是不同层次的实验接口，不应被描述为已经打通的统一控制链路。

## 4. 验证记录要求

每次验证至少记录：代码版本、目标板型号、调试器型号、串口号、构建产物、执行命令、观测结果和未验证项。没有真实硬件或探针时，只记录为“静态/仿真验证”。
