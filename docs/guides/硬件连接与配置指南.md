# 硬件连接与配置技术指南

本文档规定硬件连接与驱动程序安装的详细操作步骤。

---

## 一、所需硬件清单

### 必需硬件

- [ ] STM32 开发板（F103ZET6 或 F405RG 型号）
- [ ] 硬件调试器（CMSIS-DAP / ST-Link V2 / WCH-Link 任选其一）
- [ ] USB 数据线缆（用于连接调试器至上位机）
- [ ] SWD 排线（用于连接调试器至开发板）

### 可选硬件

- [ ] USB 转串口模块（用于查看调试日志输出）
- [ ] 杜邦线（用于串口连接）
- [ ] 外部电源适配器（当 USB 供电能力不足时使用）

---

## 二、调试器驱动安装规程

### CMSIS-DAP（野火 DAP 小智款）

**驱动程序存储路径：**
```
D:\BaiduNetdiskDownload\野火【DAP小智款下载器】
```

**安装操作步骤：**
1. 将 DAP 调试器插入上位机 USB 端口
2. 打开设备管理器，确认设备是否识别为 "CMSIS-DAP"
3. 若设备显示黄色感叹号，右键单击并选择"更新驱动程序"
4. 选择"浏览我的电脑以查找驱动程序"选项
5. 指定驱动文件夹路径完成安装

**安装验证命令：**
```bash
# Windows PowerShell 环境
Get-PnpDevice | Select-String "CMSIS-DAP"

# 预期输出
OK    USB    CMSIS-DAP v2 Interface
```

**参考文档：**
- `1-DAP小智款使用说明.pdf`
- `2-DAP下载器通用使用说明.pdf`

### ST-Link V2/V2.1

**驱动程序获取方式：**
- 官方下载地址：https://www.st.com/en/development-tools/stsw-link009.html
- 或通过搜索引擎检索 "ST-Link USB driver"

**安装操作步骤：**
1. 下载并运行 ST-Link 驱动安装程序
2. 将 ST-Link 调试器插入上位机 USB 端口
3. 设备管理器中应显示 "STMicroelectronics STLink dongle" 设备项

### WCH-Link

**驱动程序获取方式：**
- WCH 官方下载地址：https://www.wch.cn/downloads/WCH-LinkUtility_ZIP.html

**安装操作步骤：**
1. 下载 WCH-LinkUtility 工具包
2. 运行安装程序
3. 将 WCH-Link 插入上位机 USB 端口，驱动程序将自动完成安装

## 三、SWD 接口连接规程

### 标准 SWD 四线连接

```
调试器端引脚       开发板端引脚
-------------    ---------------
SWDIO    ---->   SWDIO (PA13)
SWCLK    ---->   SWCLK (PA14)
GND      ---->   GND
3V3      ---->   3V3（可选，用于向目标板供电）
```

### 信号定义表

| 信号名称 | 功能 | 说明 |
|---------|------|------|
| SWDIO | 串行数据线 | 串行数据双向传输通道 |
| SWCLK | 串行时钟线 | 串行通信时钟同步信号 |
| GND | 参考地线 | **必须可靠连接**，提供公共电位参考 |
| 3V3 | 电源线 | 可选，用于向目标板供电；若目标板已有独立电源则无需连接 |

### 常见连接错误分析

**错误类型一：遗漏 GND 连接**
- 故障现象：OpenOCD 报告 "Error: DAP init failed"
- 纠正措施：务必连接 GND 参考地线

**错误类型二：SWDIO 与 SWCLK 接线错位**
- 故障现象：OpenOCD 报告 "Error: Could not find MEM-AP"
- 纠正措施：核对 SWDIO 与 SWCLK 接线顺序

**错误类型三：目标板未上电**
- 故障现象：OpenOCD 停留在 "Listening on port 3333" 状态
- 纠正措施：为目标板接入 USB 线缆或外部电源

## 四、开发板供电规程

### 方式一：USB 供电（推荐）

```
USB 线缆 → 开发板 USB 接口
```

技术特点：接线简便；单端口最大电流 500 mA，驱动电机负载时可能供电不足。

### 方式二：外部电源供电

```
外部电源（5 V / 12 V）→ 开发板电源接口
```

技术特点：电流容量充裕，适用于带载测试场景；需严格核对电压等级与极性，防止烧毁板载器件。

### 方式三：调试器供电（仅用于调试场景）

```
调试器 3V3 引脚 → 开发板 3V3 引脚
```

技术特点：仅适用于无负载的程序调试场景，最大输出电流不超过 100 mA。

## 五、串行端口连接（可选，用于日志查看）

### 硬件连接

```
USB 转串口模块       开发板 UART1
---------------    ----------------
RX       ---->     TX (PA9)
TX       ---->     RX (PA10)
GND      ---->     GND
```

### 串口参数配置

```
波特率：115200
数据位：8
停止位：1
校验位：None
流控：None
```

### 串口监视命令

```powershell
# Windows PowerShell 环境
$port = new-Object System.IO.Ports.SerialPort COM5,115200,None,8,one
$port.Open()
$port.ReadExisting()
```

```bash
# Linux / macOS 环境
screen /dev/ttyUSB0 115200
```

## 六、连接测试规程

### 测试脚本执行

```bash
cd debug/openocd-configs
bash test-connection.sh
```

### 成功判定标准

```
Found CMSIS-DAP device
OpenOCD started successfully
Target: stm32f1x.cpu
Target voltage: 3.30V
Connection test PASSED
```

### 常见错误排查

**错误类型："Error: unable to find CMSIS-DAP device"**

```bash
# 检查 USB 设备枚举（Linux）
lsusb | grep -i "dap"

# Windows PowerShell 环境
Get-PnpDevice | Select-String "CMSIS-DAP"
```

排查流程：
1. 重新插拔 USB 连接器
2. 检查驱动程序安装正确性
3. 更换其他 USB 端口重试

**错误类型："Error: init mode failed (unable to connect to the target)"**

排查清单：
- [ ] SWD 线缆连接是否正确
- [ ] SWDIO 与 SWCLK 是否接反
- [ ] GND 参考地是否连接
- [ ] 目标板是否已接通电源
- [ ] BOOT0 跳线配置是否正确（应接 GND 侧）
- [ ] 目标板是否存在硬件故障

**错误类型："Error: Target voltage is 0.00V"**

原因分析：目标板未接通电源。
纠正措施：为开发板接入电源（USB 线缆或外部电源）。

## 七、启动模式配置规程

### STM32 启动模式表

| BOOT1 | BOOT0 | 启动区域 | 用途说明 |
|-------|-------|---------|---------|
| 任意 | 0 | 主闪存存储器 | **正常运行模式**（推荐配置） |
| 0 | 1 | 系统存储器 | DFU 模式（用于 USB 固件烧录） |
| 1 | 1 | 内置 SRAM | 调试模式（程序在 RAM 中运行） |

### 推荐配置

```
BOOT0 → GND（跳线帽短接至 GND 侧）
BOOT1 → 任意（通常亦接至 GND）
```

## 八、多调试器切换规程

本项目支持 3 类调试器，无需修改代码即可完成切换。

### Visual Studio Code 环境切换

```
1. 按 F5 快捷键或单击调试启动按钮
2. 从下拉菜单中选择对应配置项
   - Debug xxx (DAP)      ← 选用 CMSIS-DAP
   - Debug xxx (ST-Link)  ← 选用 ST-Link
   - Debug xxx (WCH-Link) ← 选用 WCH-Link
```

### 命令行环境切换

```bash
# CMSIS-DAP 调试器
openocd -f debug/openocd-configs/cmsis-dap-f103.cfg

# ST-Link 调试器
openocd -f debug/openocd-configs/stlink-f103.cfg

# WCH-Link 调试器
openocd -f debug/openocd-configs/wch-link-f103.cfg
```

## 九、硬件故障排查

### 故障现象：LED 指示灯不亮

排查清单：
- [ ] 检查电源指示灯状态
- [ ] 测量 3.3 V 与 5 V 引脚电压
- [ ] 检查 USB 线缆是否损坏
- [ ] 尝试外部电源供电方式

### 故障现象：无法完成固件烧录

排查清单：
- [ ] BOOT0 跳线是否接至 GND 侧
- [ ] SWD 连接是否可靠
- [ ] 芯片是否启用读保护（尝试执行批量擦除）
- [ ] 芯片是否损坏（使用万用表测量引脚）

### 故障现象：固件烧录后程序未运行

排查清单：
- [ ] 执行复位操作后是否正常启动
- [ ] 检查串口是否输出 HardFault 异常信息
- [ ] 晶振是否起振（使用示波器测量 OSC_IN 引脚）
- [ ] 电源稳定性是否符合要求（测量 VDD 引脚电压波动）
