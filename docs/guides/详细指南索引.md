# 详细指南区域总览

## 一、区域功能定位

docs/guides/ 区域提供面向硬件配置、调试工作流与 AI 辅助开发的**综合技术指南**。该类指南填补了快速入门文档与深度技术架构之间的知识断层，提供 STM32 调试、OpenOCD 配置、GDB 命令行工作流以及 Visual Studio Code 集成的分步操作规程。该区域作为基于 STM32 控制系统（Dummy-Arm 与 RST 夹爪固件）开发人员的主要参考来源。

## 六、使用说明

### 面向新开发人员

1. **从入口文件开始**：阅读 /e/Robotic-Arm/docs/getting-started/新用户入门指南.md，获取项目概述与导航
2. **硬件配置**：遵循 /e/Robotic-Arm/docs/guides/硬件连接与配置指南.md，安装调试器驱动、接线 SWD 连接、配置启动模式
3. **快速调试验证**：使用 /e/Robotic-Arm/docs/getting-started/调试快速上手.md 进行 5 分钟配置验证（连接调试器→运行 OpenOCD→挂载 GDB→设置断点）
4. **开发工作流**：遵循 /e/Robotic-Arm/docs/getting-started/开发工作流程.md，完成 CubeMX → Visual Studio Code → Git 循环

### 面向调试会话

1. **Visual Studio Code 图形界面调试**：参考 /e/Robotic-Arm/docs/guides/完整调试技术教程.md 中关于 Visual Studio Code 启动配置的章节（共 8 套预配置选项）
2. **GDB 命令行调试**：使用完整调试技术教程.md 中的命令参考表进行断点、监视点、寄存器检查、回溯分析
3. **HardFault 分级处置**：遵循完整调试技术教程.md 中的 HardFault 分析流程（CFSR 寄存器解码、栈展开）
4. **AI 辅助调试**：使用 /e/Robotic-Arm/docs/guides/Claude人工智能远程调试指南.md 的诊断命令模板进行 GPIO/UART/DMA/SPI 寄存器检查（注意：包含路径错误，使用时需谨慎）

### 面向 OpenOCD 配置

- **目标配置文件**：位于 /e/Robotic-Arm/debug/openocd-configs/
- **支持调试器**：CMSIS-DAP、ST-Link、WCH-Link
- **支持目标芯片**：STM32F103、STM32F405
- **自动检测脚本**：/e/Robotic-Arm/debug/test-connection.sh（138 行，自动检测调试器类型）

### 面向架构理解

- **系统概述**：阅读 /e/Robotic-Arm/docs/technical/architecture.md，获取组件图、技术栈、串行协议、坐标约定
- **已知问题**：architecture.md 编目 26 项缺陷（P0-P2），含复现步骤与变通方案状态
- **注意**：architecture.md 引用旧路径（rst-control-fw/），需与 robots/Dummy-Arm/firmware/stm32-control/ 下实际目录结构交叉核对

### 路径修正指南（临时性）

由于项目重组（提交 2603308），部分指南引用旧路径。查阅旧文档时使用以下映射关系：

| 文档中旧路径 | 实际路径 |
|-------------|---------|
| openocd-configs/ | debug/openocd-configs/ |
| rst-control-fw/control/ | robots/Dummy-Arm/firmware/stm32-control/control/ |
| robots/dummy-arm/ | robots/Dummy-Arm/（大写 D） |
| control.ioc | control/control.ioc（额外 /control/ 层级） |
| control.elf | MDK-ARM/control/control.axf（Keil 使用 .axf 格式） |

## 八、依赖项

**硬件依赖项：**
- STM32 调试器（CMSIS-DAP、ST-Link V2 或 WCH-Link）——硬件连接与配置指南.md 中有说明
- 目标硬件（STM32F103ZET6 用于 RST 夹爪、STM32F405RG 用于 Dummy-Arm）
- USB 线缆（Mini-B 用于调试器、Type-A 用于 UART）
- 3.3 V 或 5 V 电源（取决于板卡配置）

**软件依赖项：**
- OpenOCD 0.12.0-7 或更高版本（已安装，按全局上下文）
- ARM GCC 12.2 工具链或 Keil MDK-ARM（ARM GCC 已安装，存在 Keil 工程）
- Visual Studio Code 及 Cortex-Debug 扩展（共 8 套启动配置可用）
- 支持 ARM 目标的 GDB（arm-none-eabi-gdb）
- STM32CubeMX 用于代码生成（工作流记录于开发工作流程.md）
- Git 用于版本控制（已记录提交规范）

**文档依赖项：**
- docs/getting-started/新用户入门指南.md——链接至详细指南的入口文件
- docs/INDEX.md——对详细指南进行分类的导航枢纽
- debug/openocd-configs/——调试指南引用的 OpenOCD 配置文件
- 项目重组历史（提交 2603308、f2db105）——路径迁移背景

**跨指南依赖项：**
- 硬件连接与配置指南.md 为调试快速上手.md 的前置条件（必须先完成硬件连接方可调试）
