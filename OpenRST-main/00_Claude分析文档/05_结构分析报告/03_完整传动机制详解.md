## 二、三个电机的功能分配

### 2.1 M0 电机 - 控制俯仰 (Pitch)

**技术规格**：
- **关节名称**: `joint_f0_pitch` / `joint_pitch`
- **电机**: Maxon RE10 1.5W 无刷直流电机
- **减速器**: GP10A 行星减速器 1:256
- **齿轮比**: 36:32 = 1.125:1
- **总减速比**: 256 × 1.125 = **288:1**
- **运动范围**: ±90° (±1.57 rad)
- **线缆**: C3（拮抗式配置）
- **负载**: 承载整个末端执行器重量

**为什么需要最大减速比？**
- 俯仰运动需要抬起整个腕部和夹爪
- 承受重力矩最大
- 需要最大的输出扭矩

**PID 参数**：
- P = -14.0
- I = -10.0
- D = -0.414

---

### 2.4 差动偏航实现

**偏航运动 (Yaw-like motion)**：
```
M1 和 M2 同向运动 → 产生偏航效果
θ_left ≈ θ_right ≈ θ
等效偏航角 = (θ_left + θ_right) / 2
```

**抓取运动 (Grasp)**：
```
M1 和 M2 反向运动 → 产生抓取张合
θ_left = -θ_right
张合宽度 = f(θ_left - θ_right)
```

**关键优势**：
- 无需独立的偏航电机
- 简化机械结构
- 通过弧形导轨实现解耦

## 三、线缆传动的优势和设计考虑

### 3.1 线缆传动的优势

1. **远程动力传输**
   - 电机放置在基座，远离工作区域
   - 末端执行器轻量化
   - 降低末端惯量

2. **柔性结构**
   - 允许工具通过小直径通道（Ø8mm）
   - 适合微创手术应用
   - 可弯曲路径

3. **轻量化**
   - 末端无需携带电机和减速器
   - 降低能耗
   - 提高响应速度

4. **简化制造**
   - 零件数量少
   - 易于 3D 打印
   - 成本低

5. **高传动比**
   - 通过线缆绞盘可实现大减速比
   - 无需多级齿轮箱
   - 结构紧凑

---

### 3.2 线缆规格与设计

**线缆材料**：
- **类型**: 7×7 不锈钢绞线
- **直径**: 0.45mm
- **最小弯曲半径**: 2.9mm (6.5:1 弯曲比)
- **抗拉强度**: 满足 >15N 负载
- **寿命**: 考虑疲劳循环设计

**线缆配置**：
- **拮抗式布局**: 每个自由度使用一对线缆
  - 一根拉紧 → 正向运动
  - 另一根拉紧 → 反向运动
- **预紧张力**: 通过鼓轮锁定销调节
- **初始位置**: p=0° 设定基准张力

---

### 3.3 弧形导轨优化

**设计目的**：
- 最小化线缆在俯仰运动中的长度变化
- 实现爪运动与俯仰运动的解耦
- 减少控制耦合

**关键参数**：
- **导轨数量**: 8个（每条爪线缆 4 个）
- **C1 导轨**: r1L=1.4mm, k1L=-0.9mm
- **C2 导轨**: 镜像对称
- **优化结果**: 最大形变仅 **0.38mm**

**工作原理**：
```
俯仰运动时：
- 线缆路径沿弧形导轨滑动
- 路径长度近似保持不变
- 爪位置不受俯仰角度影响
```

---

### 3.4 摩擦补偿与效率

**传动效率**: **92.5%**

**摩擦来源**：
1. 线缆-滑轮摩擦
2. 线缆-导轨摩擦
3. 线缆弯曲内应力
4. 轴承摩擦

**补偿策略**：
- **PID 控制**: 针对每个关节独立调优
- **编码器反馈**: 16 CPT 增量编码器实时监测
- **前馈补偿**: 基于运动方向的摩擦模型
- **电流阈值检测**: 限位检测时的摩擦识别

## 四、10N 夹持力的实现机制

### 4.1 力的传递链

```
┌──────────────────────────────────────────────────────┐
│          从电机扭矩到夹持力的转换                     │
├──────────────────────────────────────────────────────┤
│                                                       │
│  电机扭矩: 3 mNm (Maxon RE10 额定)                   │
│       ↓ ×64 (行星减速器)                             │
│  = 192 mNm 在减速器输出                              │
│       ↓ ×1 (40:40 齿轮)                              │
│  = 192 mNm 在驱动盘                                  │
│       ↓ ÷ r_drum (线缆绞盘半径，假设 3mm)            │
│  = 192 mNm / 3mm = 64 N 线缆张力                     │
│       ↓ × 效率 (92.5%)                               │
│  = 59.2 N 有效线缆张力                               │
│       ↓ × 杠杆比 (爪长度/力臂，约 12mm/7mm)          │
│  = 59.2 N × (7/12) ≈ 34.5 N 理论夹持力               │
│       ↓ 安全系数 & 材料限制                          │
│  = 10 N 设计夹持力                                   │
│                                                       │
└──────────────────────────────────────────────────────┘
```

### 4.2 关键设计参数

**电机与减速器**：
- **电机扭矩**: 3 mNm (额定)
- **减速比**: 1:64 (夹爪用)
- **输出扭矩**: 192 mNm

**机械传动**：
- **绞盘半径**: ~3mm (需从 CAD 测量)
- **线缆张力**: 约 60N
- **传动效率**: 92.5%

**爪杠杆系统**：
- **爪长度**: ~12mm (从旋转中心到夹持点)
- **力臂**: ~7mm (从旋转中心到线缆接入点)
- **杠杆比**: 7:12

**材料强度**：
- **材料**: BioMed Amber Resin
- **抗拉强度**: 68 MPa
- **屈服强度**: 60 MPa
- **FEA 验证**: 16N 负载时应力 < 屈服强度

### 4.3 实测性能

**夹持力测试结果**：
- **平均最大夹持力**: 9.6N ✓

**定位精度**：

### 5.2 自动校准程序

**目的**: 建立编码器零点与机械限位的对应关系

```
Step 1: 各驱动盘独立旋转
       → 光传感器检测到接口盘 → 记录接口盘角度基准

Step 2: 俯仰关节正转至电流阈值（上限位）
       → 记录编码器值 θ_pitch_max

Step 3: 俯仰关节反转至电流阈值（下限位）
       → 记录编码器值 θ_pitch_min

Step 4: 俯仰关节回中位
       → θ_pitch_zero = (θ_pitch_max + θ_pitch_min) / 2

Step 5: 重复 Step 2-4 校准左爪
       → θ_left_zero

Step 6: 重复 Step 2-4 校准右爪
       → θ_right_zero

Step 7: 使能伺服控制
       → 完成校准，系统就绪
```

**电流阈值法优势**：
- 无需机械限位开关
- 软件可配置阈值
- 适应不同工具的机械限位差异
- 成本低、可靠性高

## 六、关键设计亮点

### 6.1 解耦腕机构

**创新点**：
- 通过优化的 8 个弧形导轨
- 爪运动完全独立于俯仰运动
- 线缆长度变化 < 0.38mm
- 简化控制算法

**传统设计 vs OpenRST**：
```
传统设计:
- 独立的偏航关节 → 3个电机 + 复杂机械
- Pitch-Yaw 耦合 → 复杂的运动学逆解

OpenRST 设计:
- 差动偏航 → 2个电机实现 Yaw 效果
- 弧形导轨解耦 → 简化的运动学
- 更少零件 → 更低成本
```

---

### 6.2 差动偏航

**工作原理**：
```
同向运动 (θ1 ≈ θ2):
  左爪 →  ╱
  右爪 ╱  ← 产生偏航效果
  
反向运动 (θ1 = -θ2):
  左爪 \  /
  右爪  \/  ← 产生抓取
```

**优势**：
- 无需第三个独立电机
- 降低机械复杂度
- 减少线缆干涉

---

### 6.3 快速校准

**基于电流阈值的限位检测**：
- 关节运动至机械限位
- 电机堵转电流上升
- 达到阈值 → 触发限位检测
- 记录编码器值

**优势**：
- 无机械开关
- 软件可调
- 适应性强
- 成本低

---

### 6.4 模块化设计

**三大模块**：
1. **驱动单元**: 电机 + 驱动盘 + 快换机构
2. **接口模块**: 线缆路由 + 快速连接
3. **末端执行器**: 三种夹爪可换

**优势**：
- 易于维护
- 工具快速更换（< 5秒）
- 单模块故障不影响其他
- 定制化灵活

---

### 6.5 高效传动

**92.5% 传动效率**：
- 优于典型线缆驱动系统（70-85%）
- 优化的滑轮和导轨设计
- 低摩擦材料选择
- 精确的预紧张力控制

## 总结

OpenRST 的传动机制展示了多项创新设计：

1. **288:1 高减速比** - 满足俯仰运动的大扭矩需求

4. **92.5% 高效率** - 优化的线缆传动系统
5. **自动校准** - 基于电流阈值的智能限位检测
6. **模块化快换** - < 5秒更换末端工具

整个系统通过精巧的机械设计和智能控制策略，实现了高性能、低成本、易维护的手术机器人解决方案。
