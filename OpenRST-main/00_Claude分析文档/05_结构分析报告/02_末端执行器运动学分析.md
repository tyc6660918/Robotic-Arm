## 四、差动偏航机制

### "解耦腕部机构"的含义

传统手术机器人腕部设计中，俯仰和偏航运动往往耦合，导致控制复杂。OpenRST 通过将偏航运动分解为两个夹爪的协同运动，实现了：

- **Pitch 与 Grasp 的独立控制**
- **简化的运动学模型**
- **降低线缆干涉**

### 实现方式

**偏航运动 (Yaw-like motion)**:
```
左夹爪同向运动 + 右夹爪同向运动
θ_left ≈ θ_right ≈ θ
→ 等效偏航角 = (θ_left + θ_right) / 2
```

**抓取运动 (Grasping)**:
```
左夹爪反向运动 + 右夹爪反向运动
θ_left = -θ_right
→ 张合宽度 = f(θ_left - θ_right)
```

**运动解耦**：
- 通过 **8 个优化的弧形导轨**
- 使爪运动完全独立于俯仰运动
- 最大形变仅 **0.38mm**

## 五、线缆驱动机制

### 驱动配置

使用 3 个独立的电机-线缆通道：

| 通道 | 控制目标 | 电机 | 减速器 | 线缆 | 齿轮比 | 总减速比 |
|------|---------|------|--------|------|--------|----------|
| M0 | Pitch | Maxon RE10 1.5W | GP10A 1:256 | C3 | 36:32 | **288:1** |
| M1 | Left Jaw | Maxon RE10 1.5W | GP10A 1:64 | C1 | 40:40 | **64:1** |
| M2 | Right Jaw | Maxon RE10 1.5W | GP10A 1:64 | C2 | 40:40 | **64:1** |

### 传动路径

```
驱动单元电机 
    ↓
coupling_M2_M4 联轴器
    ↓
actuation_disk 驱动盘
    ↓
interface_disk 接口盘
    ↓
线缆鼓轮 (drum) - 绞盘驱动
    ↓
导向滑轮组 (6个滑轮)
    ↓
线缆通道 (穿过不锈钢轴)
    ↓
弧形导轨 (8个优化导轨)
    ↓
末端滑轮/关节
    ↓
末端执行器运动
```

### 线缆规格

- **材料**: 7×7 不锈钢绞线
- **直径**: 0.45mm
- **弯曲半径**: 最小 2.9mm (6.5:1 弯曲比)
- **传动效率**: **92.5%**

## 六、Fenestrated（开窗式）设计

### 结构特征

从 `fenestrated_jaw_link_a/b.SLDPRT` 分析：
- 夹爪表面有规则开孔/窗口结构
- 相比 Maryland（无窗）和 Needle Driver（齿状）更轻量

### 临床优势

1. **组织抓持** - 开窗允许软组织部分进入孔内，增加摩擦力和稳定性
2. **压力分散** - 避免点接触造成的组织损伤
3. **血管保护** - 减少对血管的压迫
4. **可视化** - 医生可透过窗口观察组织状态
5. **减重** - 降低末端惯量，提高响应速度

## 七、与驱动单元的接口

### 快速更换机制

**接口模块设计**（interface_module）：

1. **机械锁定**：
   - `engagement_lever` - 卡合杆（2个）
   - `release_button` - 释放按钮（2个）
   - `release_cam` 系列 - 凸轮释放机构

2. **线缆连接**：
   - 3 对拮抗线缆通过接口模块连续传递
   - `cable_cap` 确保线缆路径稳定

3. **机械定位**：
   - interface_link 与 drive unit 之间为固定连接
   - 接口距离：133mm（从 base 到 interface）

### 分离-装配流程

**拆卸**：
```
1. 按下 release_button
2. release_cam 旋转，释放 engagement_lever
3. 末端执行器整体与驱动单元分离
4. 线缆保持在驱动单元侧
```

**安装**：
```
1. 对准三角形接口
2. 插入 attachment_base
3. 接口斜面推动 engagement_lever 向外
4. 越过卡槽后，扭簧使 lever 卡入槽中
5. 压缩弹簧将接口压紧
6. 三个光电传感器检测接口盘到位
7. 自动校准程序启动
```

### 自动校准程序

```
Step 1: 各驱动盘独立旋转至光传感器检测到接口盘
Step 2: 俯仰关节正转至电流阈值（上限位）→ 记录编码器值
Step 3: 俯仰关节反转至电流阈值（下限位）→ 记录编码器值
Step 4: 俯仰关节回中位
Step 5: 重复 Step 2-4 校准左爪
Step 6: 重复 Step 2-4 校准右爪
Step 7: 使能伺服控制 → 完成
```

## 八、运动学建模

### 正向运动学

```
T_base_to_ee = T_base_to_interface × T_interface_to_pitch × T_pitch_to_fingers

其中：
- T_pitch: 由 joint_f0_pitch 角度 θ1 决定
- T_fingers: 由 joint_f1_finger_left (θ2) 和 joint_f2_finger_right (θ3) 决定

夹爪中心位置 = f(θ1, θ2, θ3)
等效偏航角 = (θ2 + θ3) / 2  （当 θ2 ≈ θ3 时产生偏航效果）
张合宽度 = g(θ2 - θ3)
```

### 控制框架

使用 ROS 控制器框架：
- **控制器类型**: `effort_controllers/JointGroupPositionController`
- **控制模式**: PID 位置控制
- **编码器反馈**: 实时补偿摩擦和弹性变形

## 总结

OpenRST 末端执行器采用创新的**差动偏航设计**，通过两个夹爪电机的协同运动实现了传统三自由度腕部的功能。关键特点包括：

1. **解耦设计** - 通过优化的弧形导轨，爪运动完全独立于俯仰运动
2. **模块化** - 三种夹爪可快速更换
3. **高效传动** - 92.5% 的线缆传动效率
4. **自动校准** - 基于电流阈值的快速校准流程
5. **轻量化** - 3D 打印制造，末端无需携带电机

该设计非常适合微创手术应用，提供了足够的灵活性和夹持力。
