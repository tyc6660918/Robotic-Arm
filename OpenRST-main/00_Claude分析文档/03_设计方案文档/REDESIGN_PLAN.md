# MG513 电机适配 - 完整重新设计方案

**日期**: 2026-08-09  
**目标**: 将 OpenRST 驱动单元从 Maxon RE10 (Ø10mm) 适配到 WHEELTEC MG513P10 (Ø36.6mm)

---

## 📊 设计参数总结

### 电机规格对比

| 参数 | Maxon RE10 | MG513P10 | 设计影响 |
|------|-----------|----------|---------|
| **电机直径** | 10 mm | 36.6 mm | ⚠️ 安装座需扩大 3.7 倍 |
| **减速器直径** | 10 mm | 32.8 mm | ⚠️ 主要约束尺寸 |
| **总长度** | ~30 mm | 75.1 mm | ⚠️ 需要更深的空间 |
| **输出轴** | Ø2-3mm | Ø6mm D型轴 | ⚠️ 联轴器完全重新设计 |
| **轴伸长度** | ~10mm | 14mm | 🟢 差异不大 |
| **安装方式** | 专用接口 | 6×M3 螺纹孔 (Ø31mm圆周) | ⚠️ 全新安装方式 |
| **重量** | ~15g | 70g | ⚠️ 需考虑力矩平衡 |

---

## 🎯 设计策略

### 方案选择：**模块化适配器设计** ⭐

**核心思路**：
- 保留原有的 `actuation_disk` 系列（驱动盘）
- 保留原有的 `drive_unit_base` 主体结构（如果尺寸允许）
- 设计全新的**电机安装模块**，作为独立组件
- 设计全新的**联轴器**，连接 MG513 输出轴到驱动盘

**优势**：
1. 最小化对原设计的改动
2. 模块化设计便于未来更换其他电机
3. 便于 3D 打印原型验证
4. 降低设计风险

---

## 📐 需要设计的新零件

### 零件 1: 电机安装座适配器
**文件名**: `motor_mount_MG513.SLDPRT`

**功能**: 
- 安装 MG513 电机
- 与原 `drive_unit_base` 或 `attachment_base` 接口
- 提供轴承支撑（如需要）

**关键尺寸**:
```
输入侧（电机接口）:
- 中心大孔: Ø37mm (容纳 Ø36.6mm 电机本体)
- 6×M3 螺纹孔位置: Ø31mm 圆周上均布
- 孔深: 15mm (配合 M3×10 螺丝)

输出侧（与原装配体接口）:
- 待测量原 motor_base 的安装孔位
- 或设计通用安装法兰

结构:
- 材料厚度: ≥5mm (承载 70g 电机)
- 可能需要加强筋
- 线缆出口
```

**设计检查点**:
- [ ] 电机本体不与外壳干涉
- [ ] 安装螺丝有足够深度（建议用 M3×12 或 M3×15）
- [ ] 输出轴中心与驱动盘中心对齐
- [ ] 预留编码器线缆出口

---

### 零件 2: 联轴器/耦合器
**文件名**: `coupling_MG513_to_disk.SLDPRT`

**功能**:
- 连接 MG513 的 Ø6mm D型轴
- 连接到 `actuation_disk_M2` (或其他驱动盘)

**关键尺寸**:
```
输入端（电机侧）:
- 孔径: Ø6mm
- D型平边深度: 待确认 (通常 0.5-1mm)
- 键槽长度: 10-12mm
- 固定方式: M3 或 M4 顶丝

输出端（驱动盘侧）:
- 待测量原 actuation_disk 的中心孔径
- 待确认连接方式（键槽？顶丝？过盈配合？）

整体:
- 总长度: 20-30mm (留有调节余量)
- 外径: ≤20mm (不干涉其他零件)
- 材料: 铝合金或工程塑料（尼龙、PETG）
```

**设计检查点**:
- [ ] D型轴配合精度（建议 H7/h6）
- [ ] 同轴度 ≤0.1mm
- [ ] 顶丝位置对准 D型平边
- [ ] 足够的抗扭强度

### 阶段 3: 原型制造 (1-3天)

**步骤 3.1: 3D 打印验证**
```
推荐材料:
- 电机座: PETG / ABS (强度好)
- 联轴器: 尼龙 / PETG (耐磨)
- 外壳: PLA / PETG (快速原型)

打印参数:
- 层高: 0.2mm
- 填充: 50-80% (受力零件)
- 支撑: 必要时添加
```

**步骤 3.2: 装配测试**
- 检查配合精度
- 调整设计（如需要）

**步骤 3.3: 功能测试**
- 无负载转动测试
- 夹持力测试
- 编码器信号验证

### 阶段 4: 电气集成 (4-8小时)

**步骤 4.1: 驱动器选择**
```
MG513 需要有刷电机驱动器:

推荐方案 A: L298N 双路驱动板
- 电压: 5-35V ✅ 支持 12V
- 电流: 2A/路 ✅ 足够 (MG513 堵转 2A)
- 价格: ~¥10-20
- PWM 控制简单

推荐方案 B: TB6612FNG
- 电压: 4.5-13.5V ✅ 支持 12V
- 电流: 1.2A/路 (峰值 3A) ✅ 足够
- 价格: ~¥5-15
- 效率更高，体积更小

推荐方案 C: 保留 ESCON (如果支持)
- 查看 ESCON 36/2 DC 是否有有刷模式
- 可能需要重新配置参数
```

**步骤 4.2: 编码器接口**
```
MG513 (GMR 编码器版):
- 输出: AB 相增量编码器
- 分辨率: 需要从文档确认
- 电压: 通常 5V 或 3.3V

接口检查:
□ 与现有 DAQ 板兼容性
□ 信号电平匹配
□ 接插件类型 (PH2.0 6p)
```

**步骤 4.3: 控制程序调整**
- PID 参数重新整定
- 编码器计数调整（如果分辨率不同）
- 速度/加速度限制调整
