# Dummy-Arm从机机器人固件与控制系统

## 1. 区域用途

本区域包含Dummy六自由度机械臂的嵌入式固件与ROS2控制集成，该机械臂作为主从遥操作系统中的跟随设备。固件在STM32F405RG平台上基于FreeRTOS实现200Hz实时电机控制，提供基于CAN的电机协调、解析逆运动学及多种控制接口（CAN二进制协议、ASCII命令、Fibre RPC及ROS2动作服务器）。该系统通过MoveIt2将底层步进电机控制与高层运动规划桥接。

## 4. 已完成功能

- STM32F405RG固件，基于FreeRTOS实时操作系统与200Hz实时控制循环
- 六自由度机器人控制，基于DH参数运动学（L_BASE=109mm、L_ARM=146mm、L_FOREARM=115mm、L_WRIST=72mm）
- 解析逆运动学求解器，含8配置枚举
- CAN二进制协议，含30余条电机命令（0x01-0x7F），用于位置/速度/电流控制
- ASCII文本协议，用于关节空间（MoveJ：`>`、`&`）与笛卡尔空间（MoveL：`@`）运动
- Fibre RPC协议叠加层，暴露高层机器人控制API
- 7个电机的关节配置（6个臂关节加夹爪），节点ID 1-7
- 关节限位：J1 ±170°、J2 -73°至90°、J3 35°至180°、J4 ±180°、J5 ±120°、J6 ±720°、夹爪0-30°
- 齿轮减速比：J1-J3 30倍、J4 24倍、J5 30倍、J6 50倍
- 四种命令模式：顺序（阻塞）、可中断（非阻塞）、轨迹（高速）、整定（正弦）
- 带动态速度缩放的同步多关节运动
- 默认运动参数：30°/s速度、点对点低加速度（30%）、轨迹高加速度（100%）
- 安全特性：关节限位验证、单电机电流限制（默认2A，夹爪0.7A）、紧急停止
- 电机配置持久化至EEPROM（电流限制、速度限制、PID参数、自动使能、堵转保护）
- 位置反馈协议：4字节浮点加完成标志
- 通过CAN进行温度监控（命令0x25，通过0x7D可选启用）
- FreeRTOS任务架构：CommunicationTask、ControlLoopFixUpdate（实时）、ControlLoopUpdate、OledTask、RGBTask
- 命令FIFO：16槽队列，含64字节消息，阻塞/非阻塞执行
- 两阶段标定流程，L位姿[0,0,90,0,0,0]与静止位姿[0,-73,180,0,0,0]
- 用于MoveIt2集成的ROS2 FollowJointTrajectory动作服务器
- 坐标变换：关节3偏移+90°、关节5与6反转
- 双CAN总线（CAN1/CAN2 @ 1Mbps）、USB-CDC、UART4通信接口
- MPU6050 IMU集成，采用I2C接口
- SSD1306 OLED显示屏（128x80），显示关节角度与笛卡尔位姿
- RGB LED状态指示，含5种模式
- 6通道ADC（带DMA）用于模拟传感
- CMake交叉编译构建系统，含硬件FPU优化（-Ofast、FPV4-SP-D16）
- 自定义链接脚本，FreeRTOS堆位于CCM RAM（64KB）

## 6. 使用说明

### 构建固件

```bash
cd /e/Robotic-Arm/robots/Dummy-Arm/firmware/dummy-ref-core-fw
mkdir build && cd build
cmake .. -DCMAKE_TOOLCHAIN_FILE=../cmake/arm-none-eabi.cmake
make -j
```

输出：`control.elf`、`control.hex`、`control.bin`

### 烧录固件

通过OpenOCD与ST-Link：
```bash
openocd -f interface/stlink.cfg -f target/stm32f4x.cfg -c "program build/control.elf verify reset exit"
```

通过STM32CubeProgrammer：
```
File > Open > control.hex
Connect > Download > Start
```

### 串行控制（ASCII协议）

通过USB-CDC或UART4以115200波特率连接：

**关节空间运动（MoveJ）**：
```
>0,0,90,0,0,0          # 以默认速度（30°/s）移动至L位姿
>0,-73,180,0,0,0,50    # 以50°/s移动至静止位姿
&10,20,30,40,50,60     # 替代MoveJ语法
```

**笛卡尔空间运动（MoveL）**：
```
@200,0,300,0,90,0      # 移动至X=200mm、Y=0mm、Z=300mm、Roll=0°、Pitch=90°、Yaw=0°
@150,50,250,10,80,5,20 # 以20°/s关节速度进行笛卡尔移动
```

### Python控制（Fibre RPC）

```python
import fibre
from ref_tool import find_any

# 连接至机器人
robot = find_any()

# 关节空间运动
robot.move_j(0, 0, 90, 0, 0, 0)

# 笛卡尔空间运动
robot.move_l(200, 0, 300, 0, 90, 0)

# 使能/禁用电机
robot.set_enable(True)
robot.set_enable(False)

# 速度控制
robot.set_joint_speed(50)  # 设置为50°/s

# 标定
robot.homing()            # 移动至L位姿
robot.resting()           # 移动至静止位姿
robot.calibrate_home_offset()  # 两阶段标定

# 单关节控制
robot.joint_1.set_position(45.0)
robot.joint_ALL.set_enable(True)

# 夹爪控制
robot.hand.set_position(15.0)  # 半开（0-30°范围）
```

### 标定流程

1. 手动将臂定位至L位姿：J1=0°、J2=0°、J3=90°、J4=0°、J5=0°、J6=0°
2. 通过串行连接并降低J2与J3的电流限制：
   ```python
   robot.joint_2.set_current_limit(0.5)
   robot.joint_3.set_current_limit(0.5)
   ```
3. 应用第一原点偏移：
   ```python
   robot.joint_ALL.apply_position_as_home()
   ```
4. 移动至静止位姿：
   ```python
   robot.move_j(0, -73, 180, 0, 0, 0)
   ```
5. 应用第二原点偏移进行精细标定：
   ```python
   robot.joint_ALL.apply_position_as_home()
   ```
6. 恢复正常电流限制并重启：
   ```python
   robot.joint_2.set_current_limit(2.0)
   robot.joint_3.set_current_limit(2.0)
   robot.reboot()
   ```

### CAN协议（底层电机控制）

含11位标识符的二进制协议：`[NodeID:4bits][Command:7bits]`

示例命令（通过ctrl_step接口）：

```cpp
// 使能电机
motor.SetEnable(true);

// 设置位置并确认
motor.SetPositionSetPoint(90.0);  // 移动至90°

// 设置速度限制
motor.SetVelocityLimit(100.0);  // 最大速度100°/s

// 设置电流限制
motor.SetCurrentLimit(2.0);  // 2A电流限制

// PID整定
motor.SetPIDKp(0.5);
motor.SetPIDKv(0.01);
motor.SetPIDKi(0.001);
motor.SetPIDKd(0.0);

// 将当前位置应用为零点
motor.ApplyPositionAsHome();

// 请求位置反馈
motor.UpdateAngle();  // 响应：4字节浮点加完成标志

// 读取温度
motor.GetTemp();  // 响应：4字节uint32
```

### 紧急停止

通过串行：
```python
robot.emergency_stop()
```

通过CAN（需实现确认）：
```cpp
robot.CommandHandler::EmergencyStop();  // 冻结于当前位置，清空FIFO
```

注意：紧急停止不会禁用电机，仅冻结位置。安全关键应用建议外接急停电路。

## 7. 风险与限制

| 风险 | 影响 | 证据 | 缓解措施 |
|------|--------|----------|------------|
| 关节限位验证仅在软件中实现 | 高 | `dummy_robot.cpp`的MoveJ验证限位，但若固件发生bug，电机可能超出机械限位 | 添加硬件限位开关或机械硬挡块；实现位置边界检查看门狗 |
| 电流限制配置持久化于电机EEPROM | 中 | `ctrl_step.cpp`的SetCurrentLimit存储至电机闪存 - 错误值在重启后仍存在 | 在标定指南中记录安全电流范围；启动时实现固件完整性检查；添加工厂重置流程 |
| 紧急停止不会禁用电机 | 高 | 紧急停止冻结位置但电机仍通电 - 无电源切断 | 添加切断电机电源的外接急停电路；在安全手册中记录该限制 |
| 电机通信丢失无看门狗 | 中 | 若CAN反馈从电机节点停止到达，无已记录的超时 | 在控制循环中添加通信看门狗；若位置反馈缺失超过100ms，触发安全状态 |
| 标定需手动定位 | 中 | 两阶段标定流程取决于操作员定位L位姿的精度 | 添加可视化标定夹具或对准指南；若硬件允许，通过限位开关实现自标定 |
| CAN总线错误恢复依赖HAL_CAN_ErrorCallback | 中 | `interface_can.cpp`中的传输失败若无错误处理程序可能被忽略 | 添加CAN错误计数器与日志；实现带指数退避的重试逻辑 |
| 命令FIFO溢出静默丢弃命令 | 中 | 16槽队列（64字节消息）在高命令速率下可能溢出 - 无主机反馈 | 添加FIFO满检测；向主机返回错误码；实现流控制或动态队列大小 |
| 温度监控为可选 | 中 | 必须通过命令0x7D显式启用监控 - 若禁用可能发生热过载 | 固件中默认启用温度监控；添加热关断阈值 |
| 固件中无碰撞检测 | 低 | 固件无自碰撞或工作空间边界检查 - 完全依赖MoveIt2规划 | 在固件中添加基础关节空间碰撞区域；实现工作空间包围盒检查 |
| USB重新连接可能使电机处于未知状态 | 中 | 运动过程中USB断开后无已记录的状态恢复 | 添加连接看门狗；通信丢失时实现安全状态；建议断开后执行电源循环 |

2. **验证关节限位强制执行** - 通过所有协议（ASCII、Fibre、ROS2）发送越界命令，验证拒绝逻辑
3. **测量紧急停止响应时间** - 在高速运动过程中触发紧急停止，测量减速度曲线与停止距离
4. **定位并审查电机固件** - 查找电机节点1-7的源代码，理解DCE PID算法、堵转检测及EEPROM磨损均衡
5. **测试EEPROM持久化** - 配置电机参数（电流限制、PID增益、自动使能），断电循环，验证跨重启的持久化
6. **记录温度监控** - 启用温度监控（0x7D），表征负载下的热响应，识别故障阈值
7. **分析轨迹平滑** - 发送多航点MoveJ序列，捕获关节轨迹，测量点间加速度连续性
8. **测试CAN总线错误恢复** - 模拟CAN错误（电缆断开、总线关闭状态），验证HAL_CAN_ErrorCallback行为与恢复
9. **实现命令FIFO监控** - 添加队列深度遥测，测试溢出条件，测量主机到固件的命令延迟
10. **验证USB重新连接** - 运动过程中断开并重新连接USB，验证安全状态转换与Fibre重新发现的鲁棒性
11. **测试堵转保护** - 启用堵转保护（0x1B）时在负载下阻挡关节，验证检测与恢复行为
12. **表征IMU使用** - 在扰动（外部推动）期间记录IMU数据，检查控制循环是否使用姿态反馈进行稳定
13. **构建并测试ROS2工作空间** - 安装colcon，构建moveit2_ws，通过MoveIt2 RViz接口验证FollowJointTrajectory动作服务器
14. **验证坐标变换** - 通过ROS2与Fibre发送相同关节命令，验证J3 +90°偏移及J5/J6反转的正确性
15. **创建命令延迟基准测试** - 测量从主机命令（ASCII/Fibre/ROS2）到各协议运动开始的端到端延迟
