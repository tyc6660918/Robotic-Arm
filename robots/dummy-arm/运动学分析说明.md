# Dummy从臂运动学

## 1. 区域用途

本区域实现Dummy六自由度机械臂的正运动学与逆运动学求解器。提供两套并行逆运动学实现：优化用于PC端轨迹规划的数值求解器（Python/SciPy，P99 < 20ms）及用于实时固件控制的嵌入式解析求解器（C++，闭式6R解，含8个配置分支）。该区域建立运动学模型（URDF/DH参数）、强制执行安全关节限位、定义工作空间边界，并通过正运动学→逆运动学→正运动学往返测试验证精度。

## 4. 已完成功能

**数值逆运动学求解器（Python/Windows仿真 - 生产级）**
- 基于信赖域反射法的SciPy least_squares，在100Hz下1000步跟踪实现P99 < 20ms
- 代价函数：加权位置 + SO(3)旋转误差 + 居中 + 连续性正则化
- 解析几何雅可比，采用SO(3)右雅可比逆计算姿态残差
- 容差：位置 ≤ 0.1mm、姿态 ≤ 0.05°（0.00087 rad）
- 有界优化，在所有6个关节上强制执行安全限位
- 热启动跟踪，使用上次解作为种子（max_nfev=15），冷启动多起点引导（max_nfev=300，fallback_starts=12）
- 优雅失败行为：返回上次接受解以启用HOLD状态

**解析逆运动学求解器（C++/固件 - 嵌入式）**
- 6R串联臂的闭式几何解，返回8个逆运动学配置（2肩部 × 2肘 × 2腕分支）
- 配置选择：选择最接近当前关节状态的分支（最小关节空间距离）
- DH参数：L_BASE=109mm、D_BASE=35mm、L_ARM=146mm、L_FOREARM=115mm、D_ELBOW=52mm、L_WRIST=72mm
- 腕部奇异点处理：cosq5 = ±1.0情形使用上次有效J4/J6，重新计算J5
- 三级有效性标志[肩部, 肘, 腕]指示可达性与分支有效性
- 后处理：角度包裹至[-π,π]、弧度→角度转换、对照硬件限位验证

**模型验证**
- 正运动学→逆运动学→正运动学往返：30组随机配置收敛，位置误差 < 0.1mm、姿态误差 < 0.05°
- 雅可比验证：解析与数值中心差分一致，rtol=2e-6、atol=2e-7
- 奇异点穿越测试：41步路径通过腕部奇异点（J5：10°→-10°）保持连续性，最大步长 < 0.55°
- URDF已对照固件DH参数验证：舍入误差内匹配
- 正运动学零配置测试：位置与URDF原点和匹配至12位小数

## 6. 使用说明

**运行数值逆运动学（Python/Windows仿真）**

```python
from sim.ik_solver import BoundedIKSolver
from sim.kinematics import SerialKinematics

# 初始化运动学与逆运动学求解器
kinematics = SerialKinematics(urdf_path="robots/Dummy-Arm/moveit2_ws/dummy-ros2_description/urdf/dummy.urdf")
ik_solver = BoundedIKSolver(kinematics)

# 求解目标位姿的逆运动学
target_position = np.array([0.2, 0.1, 0.3])  # 单位：米
target_orientation = np.array([[1,0,0],[0,1,0],[0,0,1]])  # 旋转矩阵
result = ik_solver.solve(target_position, target_orientation, q_init=current_joint_angles)

if result.success:
    joint_angles = result.q  # 单位：弧度
    print(f"逆运动学收敛于{result.nfev}次迭代，耗时：{result.solve_time_ms:.2f}ms")
```

**运行嵌入式解析逆运动学（固件）**

```cpp
// 固件中：dummy-ref-core-fw/Robot/algorithms/kinematic/6dof_kinematic.cpp
DOF6Kinematic ik_solver;
float target_pose[6] = {x_mm, y_mm, z_mm, rx_deg, ry_deg, rz_deg};
float current_joints[6] = {j1_deg, j2_deg, j3_deg, j4_deg, j5_deg, j6_deg};
float solution[6];
uint8_t validity_flags[3];  // [肩部, 肘, 腕]

// 计算逆运动学（返回8个解，选择最接近current_joints者）
bool success = ik_solver.inverse_kinematics(target_pose, current_joints, solution, validity_flags);
if (success && validity_flags[0] && validity_flags[1] && validity_flags[2]) {
    // 所有分支有效，solution含角度制关节角
}
```

**坐标系约定**

- URDF基坐标系：Z轴向上、右手定则
- 零配置正运动学结果：位置[-0.016, -0.290517, 0.318]m、姿态单位矩阵
- 硬件映射需偏移/反转：J3_硬件 = J3_ROS + 90°、J5_硬件 = -J5_ROS、J6_硬件 = -J6_ROS

**关节限位强制执行**

安全限位（刻意紧于URDF以防止自碰撞）：
- 关节1：[-170°, 170°]（URDF：[-180°, 180°]）
- 关节2：[-73°, 90°]（URDF：[-75°, 90°]）
- 关节3：[-55°, 90°]（URDF：[-90°, 90°]，固件：+90°偏移后为[35°, 180°]）
- 关节4：[-180°, 180°]（全旋转）
- 关节5：[-90°, 90°]
- 关节6：[-180°, 180°]（全旋转）

## 7. 风险与限制

| 风险 | 影响 | 证据 | 缓解措施 |
|------|--------|----------|------------|
| 腕部奇异点（J5≈0°）导致逆运动学分支歧义 | 中 | 当前求解器使用上次有效J4/J6，但遥操作期间可能导致不连续跳变 | 记录奇异点规避策略，在轨迹规划器中实现速度连续性检查 |
| 数值逆运动学P99性能（20ms）超出1kHz控制循环预算 | 高 | `test_ik_performance.py`验证20ms P99延迟，典型实时控制要求 < 1ms | 在独立线程中运行逆运动学并采用外推回退，或使用嵌入式解析求解器进行实时控制 |
| 安全关节限位比硬件限位紧15° | 低-中 | 工作空间缩减约8%，可能拒绝边界附近的有效位姿 | 不存在用于自碰撞检测的碰撞网格 - 接受工作空间缩减或添加碰撞几何 |
| J3偏移映射（+90° L位姿标定）为固件约定 | 中 | ROS URDF与硬件角度间的不匹配在部署期间需仔细验证 | `hardware_mapping.py`记录变换，生产使用前在硬件上验证 |

## 8. 依赖项

**Python/仿真依赖**
- SciPy（数值逆运动学的优化库，`scipy.optimize.least_squares`）
- NumPy（矩阵运算、几何变换、`numpy.linalg`）
- URDF解析器（机器人模型加载、关节树遍历）

**嵌入式/固件依赖**
- CMSIS-DSP（固件正运动学/逆运动学的嵌入式`arm_cos_f32`/`arm_sin_f32`）
- STM32 HAL（电机控制接口的硬件抽象）

**ROS2/MoveIt2依赖**
- MoveIt2 KDL插件（ROS2运动规划，`kdl_kinematics_plugin`）
- URDF/XACRO（机器人模型定义，`robot_state_publisher`）
- ROS2 Humble或更高版本（中间件、动作服务器）
