# 参考控制器硬件说明

PCB 文件下载地址：<https://dummy.mbbs.cc/#/thread/detail/67>

## 对比原始设计的改进项

1. 简化电路设计，更适用于量产场景
2. 原 1.0mm 间距连接器全部更换为 1.5mm 插针连接器，修复了原版连接器易脱落的问题
3. 删除独立 base 板，将 base 板电路集成至主板
4. 新增开关型低压差线性稳压器（Switching LDO），最大供电电流提升至 2A，修复了原版 MCU LDO 电流过小、温度过高的问题
5. LED 环形灯与蜂鸣器控制从 ESP32 迁移至 STM32 主控
6. 优化元器件布局，提升电气性能与可制造性
7. 降低整体量产成本
