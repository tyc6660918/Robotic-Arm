# 伺服流式控制最佳实践指南

## 1. 概述

本指南系统阐述了基于MoveIt Servo组件在Dummy机械臂平台上实现高频、低延迟流式运动控制的完整集成方案。该方案适用于视觉伺服闭环、实时遥操作及流畅视教数据采集等对控制延迟具有严格要求的应用场景。

## 2. 系统架构与文件清单

为规避传统MoveGroup规划-执行模式所固有的高延迟问题，本方案采用**MoveIt Servo实时计算引擎 + Python硬件桥接节点**的两级架构。

### 2.1 修改及新增文件明细

1. **`src/dummy_controller/dummy_controller/dummy_servo_hardware.py`（新增）**
   - **功能定位**：硬件驱动桥接层。
   - **核心功能**：以50 Hz频率订阅`/servo_node/command`话题，提取目标关节角度后，即刻通过Fibre协议调用`move_j`接口下发至下位机控制器；同时以50 Hz频率发布`/joint_states`话题，为RViz可视化与Servo引擎闭环计算提供实时关节状态反馈。

2. **`src/dummy_moveit_config/config/servo_streaming.yaml`（新增）**
   - **功能定位**：MoveIt Servo核心参数配置文件。
   - **核心功能**：配置笛卡尔空间与关节空间的速度/加速度约束、奇异点检测阈值、自碰撞检测参数，以及输入输出话题的映射关系。

3. **`src/dummy_moveit_config/launch/servo_streaming.launch.py`（新增）**
   - **功能定位**：流式模式一键启动脚本。
   - **核心功能**：按依赖顺序组合启动RViz可视化环境、MoveIt Servo计算节点、Python硬件桥接节点及Robot State Publisher节点。

4. **`src/dummy_controller/setup.py`（修改）**
   - **功能定位**：节点入口注册文件。
   - **核心功能**：新增`dummy_servo_hardware`节点的可执行入口声明，确保构建后可通过ROS 2命令行工具直接调用。

## 3. 构建与运行流程

以下操作均需在工作空间根目录下执行。

### 3.1 编译与环境配置

```bash
# 仅编译受本次修改影响的功能包，加速构建过程
colcon build --packages-select dummy_controller dummy_moveit_config
# 刷新当前终端的ROS 2环境变量
source install/setup.bash
```

### 3.2 启动流式控制模式

```bash
ros2 launch dummy_moveit_config servo_streaming.launch.py
```

启动完成后，RViz可视化界面将自动加载，并实时显示机械臂当前姿态的镜像反馈。

## 4. 指令下发与状态监控

### 4.1 Servo引擎激活（需注意事项）

出于安全设计原则，MoveIt Servo节点启动后默认处于**待机锁定状态**。每次执行launch文件启动后，必须显式调用一次服务接口以激活引擎：

```bash
ros2 service call /moveit_servo/start_servo std_srvs/srv/Trigger
```

激活成功后，通过`ros2 topic echo /servo_node/status`订阅状态话题，可观察到状态值开始稳定输出（常规运行状态通常为0）。

### 4.2 流式运动指令下发

需通过Python程序或终端工具向`/servo_node/delta_twist_cmds`话题持续发布`TwistStamped`类型消息，消息中的速度向量将被Servo引擎实时解析并转换为关节增量指令。

**终端测试示例（令末端执行器沿X轴以0.05 m/s匀速平移）：**

```bash
ros2 topic pub --rate 50 /servo_node/delta_twist_cmds geometry_msgs/msg/TwistStamped "
{
  header: { stamp: {sec: 0, nanosec: 0}, frame_id: 'base_link' },
  twist: {
    linear: {x: 0.05, y: 0.0, z: 0.0},
    angular: {x: 0.0, y: 0.0, z: 0.0}
  }
}"
```

### 4.3 运行状态检查项

1. **RViz可视化一致性**：RViz中的三维模型应与真实机械臂动作保持实时同步。若出现RViz模型静止现象，应优先检查`/joint_states`话题是否存在数据输出。
2. **安全制动触发**：若机械臂出现非预期停机，应立即查看终端日志输出。MoveIt Servo内置安全机制将在机械臂趋近奇异构型（Singularity）或即将发生自碰撞时自动执行紧急制动。
3. **引擎健康监控**：通过`ros2 topic echo /servo_node/status`持续监测Servo引擎运行状态（Status=1表示一切正常）。

## 5. 需注意事项与已知问题

- **指令连续性约束**：Servo引擎采用"死人开关"（Dead Man's Switch）安全机制。若指令发布中断时长超过`incoming_command_timeout`参数阈值（默认0.1秒），机械臂将立即执行紧急停机。
- **下位机执行抖动**：若下位机执行`move_j`指令时出现位置抖动，应检查下位机控制器是否支持"透传模式"（Direct Passthrough Mode），或考虑关闭内部的加减速曲线规划功能以消除两级规划冲突。
