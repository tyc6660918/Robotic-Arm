# 基于MoveIt Servo的流式接口开发文档

## 1. 概述

本文档定义了基于MoveIt Servo组件实现机械臂末端笛卡尔空间流式控制的接口规范与调用示例。所有控制指令通过ROS 2话题以增量速度（Twist）形式持续发布，支持末端执行器的六自由度实时运动控制。

## 2. 发布频率与参数说明

- **话题名称**：`/servo_node/delta_twist_cmds`
- **消息类型**：`geometry_msgs/msg/TwistStamped`
- **坐标系**：`base_link`（机械臂基坐标系）
- **推荐发布频率**：50 Hz（通过`--rate 50`参数指定）
- **指令超时机制**：若停止发布超过0.1秒，Servo引擎将触发安全停机
- **线速度单位**：m/s（本示例默认速度幅值为 0.05 m/s）
- **角速度单位**：rad/s（本示例默认速度幅值为 0.1 rad/s）

## 3. 笛卡尔空间平移控制

### 3.1 X轴正向平移

沿基坐标系X轴正方向以0.05 m/s的线速度持续移动末端执行器。

```bash
ros2 topic pub --rate 50 /servo_node/delta_twist_cmds geometry_msgs/msg/TwistStamped "{header: {stamp: 'now', frame_id: 'base_link'}, twist: {linear: {x: 0.05, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 0.0}}}"
```

## 5. 定长时长控制示例

### 5.1 Y轴负向平移（持续0.5秒）

以50 Hz频率发布25帧消息，实现约0.5秒的定长时间运动。该方式适用于需要精确控制运动时长的场景。

```bash
ros2 topic pub --rate 50 -t 25 /servo_node/delta_twist_cmds geometry_msgs/msg/TwistStamped "{header: {stamp: 'now', frame_id: 'base_link'}, twist: {linear: {x: 0.0, y: -0.05, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 0.0}}}"
```

## 6. 参考坐标系约定

所有平移与旋转指令均基于机械臂基坐标系（`base_link`）：
- **X轴**：定义为机械臂安装平面内的指定水平方向
- **Y轴**：定义为机械臂安装平面内与X轴正交的水平方向
- **Z轴**：定义为垂直于安装平面向上的方向
- **旋转正方向**：遵循右手定则，拇指指向坐标轴正向时四指环绕方向为旋转正方向
