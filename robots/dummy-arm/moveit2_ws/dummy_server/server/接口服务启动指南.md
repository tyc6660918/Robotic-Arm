# 接口服务启动指南

本指南说明Dummy机械臂MoveIt 2 HTTP接口服务的启动方法。

## 前置条件

1.  **ROS 2 Humble环境**：确保ROS 2已完成安装并完成环境配置。
2.  **MoveIt 2核心组件**：机器人的MoveIt 2配置与控制器需处于运行状态。
3.  **Python依赖库**：
    *   `fastapi`
    *   `uvicorn`
    *   `pydantic`
    *   `rclpy`（ROS 2内置组件）

---

## 启动步骤

### 1. 启动机器人与MoveIt 2
在启动接口服务前，需确保机器人的MoveIt 2环境已激活。在新终端中执行：

```bash
# 配置ROS 2与工作空间环境
source /opt/ros/humble/setup.bash
source install/setup.bash

# 启动MoveIt 2演示（仿真模式或实体机器人）
ros2 launch dummy_moveit_config demo.launch.py
```

### 2. 启动接口服务
当MoveIt 2就绪后（RViz已打开且机器人状态已加载），打开另一终端：

#### 方案A：使用`ros2 run`（推荐）
若已通过`colcon build`完成工作空间构建：

```bash
source /opt/ros/humble/setup.bash
source install/setup.bash

ros2 run pymoveit2 api_server.py
```

#### 方案B：直接Python执行
若处于开发阶段，希望直接运行脚本：

```bash
source /opt/ros/humble/setup.bash
source install/setup.bash

python3 src/dummy_server/server/api_server.py
```

---

## 代码变更生效方法（重新构建）

若修改了`api_server.py`、`pymoveit2/`中的核心库或任何配置文件，需确保变更在运行系统中生效。

### 采用`ros2 run`方式时：
需重新构建软件包以更新已安装文件：

```bash
# 在工作空间根目录执行
colcon build --packages-select pymoveit2

# 重新配置工作空间环境
source install/setup.bash

# 重启接口服务
ros2 run pymoveit2 api_server.py
```

> **开发优化建议**：首次构建时使用`colcon build --symlink-install`参数。该方式将创建符号链接而非复制文件，因此Python脚本的变更在进程重启后立即生效，无需再次执行`colcon build`。

### 采用直接Python执行方式时：
只需重启进程（Ctrl+C后再次运行命令），无需构建步骤。

## 启动验证

服务启动后，可通过`http://localhost:8000`访问。可通过状态接口验证服务运行状态：

```bash
curl http://localhost:8000/api/status
```

**预期响应**：
```json
{"status": "ok", "robot_state": "IDLE", "current_joints": [...]}
```

---

## 故障排查

*   **未找到MoveIt 2**：确保在启动接口服务的终端中已执行`install/setup.bash`的环境配置。
*   **端口8000冲突**：若8000端口已被占用，可在`api_server.py`文件底部修改端口配置：
    ```python
    uvicorn.run(app, host="0.0.0.0", port=8000)
    ```
*   **关节状态缺失**：若接口返回关节状态相关错误，请确认机器人状态发布器正在运行（通常包含于`demo.launch.py`中）。
