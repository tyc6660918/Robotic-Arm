## 使用说明

### 验证目标

完成 MCU 最小系统验证，实现串口通信功能。本阶段不连接电机。

---

### 第一步：最小系统接线（预计 5 分钟）

#### ST-Link 烧录器连接：
```
ST-Link          野火霸道板
SWDIO    ─────→  PA13 (SWD接口)
SWCLK    ─────→  PA14 (SWD接口)
GND      ─────→  GND
```
**说明：** 野火板设有专用 SWD 接口，可直接插接 ST-Link 设备。

#### USB 线缆连接（供电与串口复用）：
```
电脑 USB 端口  ─────→  野火板 USB 接口
```
**说明：** 野火板集成 CH340 USB 转串口芯片，单根 USB 线缆可同时实现供电与调试功能。

#### 接线范围限制：
- 不连接电机
- 不连接驱动板
- 不连接编码器
- 不连接 12V 外部电源

---

### 第二步：CubeMX 工程配置（预计 10 分钟）

#### 1. 打开工程文件
```
双击打开：rst-control-fw/rst-control-fw.ioc
```

#### 2. 配置 TIM6 定时器（必要配置）
- 左侧导航栏 **Timers** → 选择 **TIM6**
- 勾选 `Activated` 选项
- 进入 **Configuration** → **Parameter Settings**：
  - Prescaler 参数设置为：`35`
  - Counter Period 参数设置为：`99`
- 进入 **NVIC Settings**：
  - 勾选 `TIM6 global interrupt` 选项
  - Priority 参数设置为：`0`

#### 3. 配置 ADC1 与 DMA（必要配置）
- 左侧导航栏 **Analog** → 选择 **ADC1**
- **Mode** 设置：
  - IN3：勾选 `ADC1_IN3`
  - IN4：勾选 `ADC1_IN4`
  - IN5：勾选 `ADC1_IN5`
- 进入 **Configuration** → **Parameter Settings**：
  - Scan Conversion Mode：设置为 `Enable`
  - Continuous Conversion：设置为 `Enable`
  - DMA Continuous Requests：设置为 `Enable`
  - Number of Conversion：设置为 `3`
- 进入 **DMA Settings** → 点击 **Add** 按钮：
  - DMA Request：选择 `ADC1`
  - Mode：选择 `Circular`
  - Data Width：两项均选择 `Half Word`

#### 4. 生成工程代码
```
点击界面右上角 [GENERATE CODE] 按钮
```

---

### 第三步：Keil 工程编译（预计 5 分钟）

#### 1. 打开工程文件
```
双击打开：rst-control-fw/MDK-ARM/rst-control-fw.uvprojx
```

#### 2. 添加源文件至工程
- 在左侧 **Project** 窗口中
- 右键点击 `Application/User/Core` → 选择 `Add Existing Files to Group`
- 选择以下文件：
  - `Core/Src/control_loop.c`
  - `Core/Src/tim6.c`

#### 3. 执行编译
```
按 F7 键或点击工具栏 Build 图标
```

编译通过判定标准：
```
0 Error(s), 0 Warning(s)
```

---

### 第四步：固件烧录（预计 2 分钟）

#### 1. 确认连接状态
- ST-Link 已插入电脑 USB 端口
- ST-Link 另一端已连接野火板 SWD 接口

#### 2. 执行下载
```
Keil 中按 F8 键或点击工具栏 Download 图标
```

烧录通过判定标准：
```
Programming Done
Verify OK
```

---

### 第五步：串口通信测试（预计 2 分钟）

#### 1. 定位串口编号
- 打开 Windows **设备管理器**
- 进入 **端口(COM 和 LPT)** 分类
- 定位 `USB-SERIAL CH340 (COMx)` 条目
- 记录实际端口号（示例：COM3）

#### 2. 启动串口终端工具
推荐工具（任选其一）：
- SSCOM（串口调试助手）
- MobaXterm
- Tera Term
- PuTTY

#### 3. 串口参数配置
```
端口号：COMx（使用实际分配的端口号）
波特率：115200
数据位：8
停止位：1
校验位：None
```

#### 4. 建立连接
点击 **打开串口** 或 **Connect** 按钮。

---

### 验证通过判定标准

串口终端应显示以下启动信息：
```
========================================
  RST Motor Controller - Debug Console
  STM32F103ZET6  |  3-Axis DC Motor
========================================
  CAN ID=8  |  输入 help 查看命令
>
```

#### 功能测试命令
```
输入命令：help
预期输出：显示全部命令列表

输入命令：info
预期输出：系统信息面板
说明：Loop Cnt 字段恒为 0 属于当前固件已知状态，非故障现象。
      loop_count 变量在代码中未执行自增操作，且 20kHz 控制循环未实际启动。
      详细说明参见 固件真实状态.md。

输入命令：led 1 blink
预期输出：LED 闪烁测试（若板载对应 LED 已连接）

输入命令：dip
预期输出：拨码开关状态读数
```

### 异常处置

#### 编译阶段异常
| 错误信息 | 可能原因 | 处置方法 |
|---------|---------|---------|
| `undefined reference to TIM6_IRQHandler` | CubeMX 未正确配置 TIM6 | 返回第二步重新执行 TIM6 配置 |
| `cannot open source file "control_loop.c"` | Keil 工程未添加对应源文件 | 返回第三步重新执行添加文件操作 |

#### 烧录阶段异常
| 错误信息 | 可能原因 | 处置方法 |
|---------|---------|---------|
| `No Target Connected` | ST-Link 连接异常 | 检查 SWD 接线状态 |
| `Flash Download failed` | 芯片写保护 | Keil → Flash → Erase Full Chip |

#### 串口通信异常
| 现象 | 可能原因 | 处置方法 |
|------|---------|---------|
| 无法定位 COM 端口 | 驱动程序未安装 | 安装 CH340 驱动程序 |
| 串口打开失败 | 端口被其他程序占用 | 关闭其他串口终端工具 |
| 输出乱码 | 波特率配置错误 | 确认波特率参数为 115200 |
| 无任何输出 | MCU 未复位 | 按下开发板 RESET 按钮 |

## 风险与局限

- 当前固件处于开发阶段，Loop Cnt 恒为 0 为预期状态，不可作为控制环运行判据
- 阶段 1 通过仅表明 MCU 与串口链路正常，不可直接推断电机、编码器等外围功能可用
- 完成阶段 1 验证后，不可直接进入电机连接测试，需先按 `固件真实状态.md` 修复阻塞性问题
