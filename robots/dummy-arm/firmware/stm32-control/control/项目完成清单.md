固件**已实现编译通过、烧录成功、串口控制台交互**等基础功能。但**电机驱动功能未启动、编码器计数功能未启动、LED/按键/拨码开关功能失效、`Loop Cnt` 字段恒为 0**——上述问题的根因为若干处外设初始化调用缺失，非硬件层面故障。

CubeMX 本次代码生成操作**已清空 `gpio.c` 文件中手写的引脚配置**（含 LED、按键、拨码开关、电机方向引脚）。此为当前 LED 与按键功能失效的直接原因。在执行修复前，严禁再次点击 Generate Code 按钮。

### 常见问题解答

#### Q: `info` 输出中 `Loop Cnt` 字段数值不递增？
**A:** 该现象为当前代码的必然结果，非硬件或烧录问题。`MX_TIM6_Init()` 函数未被调用，`HAL_TIM_Base_Start_IT()` 直接返回 `HAL_ERROR`，TIM6 外设从未使能。重新执行 CubeMX 代码生成无法解决该问题，反而将再次清空 `gpio.c` 文件内容。仅需修改 `main.c` 补充对应调用语句即可。

#### Q: `pwm 0 500` 命令提示成功但电机不转动？
**A:** 两项原因叠加：PWM 通道未执行 Start 操作；方向引脚所在 GPIOB 端口时钟未使能。

#### Q: 静止状态下角度字段显示 4915 度？
**A:** `RST_SafeStartup()` 函数将编码器计数值预置为 32768，但角度换算逻辑未减去该偏置值。32768 × 360 / 2400 = 4915.2 度。

#### Q: Keil 编译失败 / 找不到 CMSIS-DAP 设备 / 烧录失败 / 串口无输出？
**A:** 参考 `control/编译烧录指南.md`，该部分流程有效。串口通信问题应重点确认端口号、波特率 115200、TX/RX 交叉连接正确性。

## 风险与局限

### 当前阶段（阶段 1）安全状态

```
仅连接 DAP 下载器与 CH340 串口模块
仅使用 USB 端口供电（5V）
不连接电机 / 驱动板 / 12V 外部电源
```

上述配置下不存在硬件损坏风险。

### 电机连接前置安全提示

当前固件版本**未实现任何软件层面的电机保护机制**：无电流限幅、无堵转检测、无指令超时、无看门狗、无软件紧急停止功能，`Error_Handler` 异常处理函数亦不会关闭 PWM 输出。

**当前唯一可靠的保护措施为物理断电开关。** 必须串联物理断电开关，并优先使用具备限流功能的实验电源。
