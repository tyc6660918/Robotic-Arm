【必须澄清的六项虚假声明】

1. "PID 控制器 — 完整实现"
   → 代码里没有 PID。control_loop.c:132-140 无论使能与否
     都写 pwm_output = 0, 注释仍是 "完整实现需要 PID 控制器"。

2. "归零状态机 — 堵转检测自动寻找机械零点"
   → 不存在。homing_step / homing_stall_cnt 只被清零, 从未被读写。

3. "堵转保护 — 电流+速度双重判断" / "默认 1.5A 触发"
   → 不存在。STALL_CURRENT_MA 这个宏在代码中根本没有定义。

4. "241 行完整控制循环"
   → control_loop.c 实际 141 行, 其中控制逻辑约 8 行且是空操作。

5. "20kHz 硬实时中断"
   → MX_TIM6_Init() 从未被调用 → htim6.State 停在 RESET →
     HAL_TIM_Base_Start_IT() 首行即 return HAL_ERROR (静默失败)。
     串口仍会打印 "Control loop started at 20kHz", 该行是假消息。

6. "启动前所有电机刹车"
   → RST_SafeStartup() 只清结构体, 从未调用 Motor_Brake()/
     Motor_Sleep()。所幸 GPIO 复位值为 0 = TB6612 惰行, 属
     "碰巧安全"而非设计。

【本轮新引入的严重回退】⚠️

gpio.c 被 CubeMX 重新生成, 手写的引脚配置全部丢失。
现在 MX_GPIO_Init() 只剩三行时钟使能 (GPIOC/A/D), 并且:

  ✗ GPIOB 时钟未使能 → 6 个电机方向脚全部失效
  ✗ GPIOE 时钟未使能 → 4 个 LED + 2 个按键全部失效
  ✗ LED/按键/DIP/方向脚 一个都没有 HAL_GPIO_Init()

后果: led/btn/dip 三条命令读写的是未配置引脚, 返回值无意义;
Motor_SetDirection() 写 GPIOB 完全无效。

同时 DIP 拨码读取逻辑被删除, can_node_id 被硬编码为 0
(control_loop.c:39), 但 info 命令仍打印 "CAN ID: 8"。

【"Loop Cnt 在增加" 不能作为验收标准】⚠️

多份文档把 "info 显示 Loop Cnt 在增加" 当作 20kHz 控制环
正常运行的判据。这个判据双重失效:

  (1) TIM6 从未启动, 控制环一次都不会执行;
  (2) 即使启动了, g_rst.loop_count 在整个工程里也只被
      赋值为 0 一次 (control_loop.c:41), 没有任何 ++ 操作。

所以 Loop Cnt 永远显示 0。看到 0 是正常的, 不代表烧录失败。

【沿用未修的旧问题】

  ADC Rank3 通道配错 (adc.c:79 只改 Rank 未改 Channel)
    → PA5 上夹电流永远采不到, PA3 被采两次
  ADC 仍是 ContinuousConvMode=DISABLE + 软件触发
    → 配 DMA circular 也只跑一轮就停
  CAN 实际 562.5kbps 不是 1Mbps
    → APB1=36MHz, Prescaler=4/BS1=13/BS2=2; 文档误用了 72MHz
    → 上位机按 1Mbps 配置会完全通不上; info 打印的 "1Mbps" 是错的
  CAN 无滤波器 + 未 ActivateNotification → 收不到任何报文
  TIM2 编码器仍在 PA0/PA1 (PA0 是文档明令禁用的 WK_UP 按键脚)
  PWM 仍是 1kHz, 与 20kHz 控制环差 20 倍 (量级冲突, 且在可听频段)
  PWM_MAX_DUTY=1000 > ARR=999 (标度 off-by-one)
  Error_Handler 只 __disable_irq() + 空死循环, 不关 PWM
  无 IWDG / 无指令超时 / 无电流限幅 / 无急停
  ReadEncoders 角度用绝对计数且零点预置 32768 → 上电报 4915°
  指定的 P<>U<>L<> / CALIB / PING 串口协议仍然零命中

【下一步 — 按此顺序】

只改代码就能做的 (不用动 CubeMX):

  1. main.c 补 MX_TIM6_Init(); (在 MX_TIM8_Init() 之后)
     并检查 HAL_TIM_Base_Start_IT() 返回值, 失败要报错不要静默
  2. 把丢失的 GPIO 配置写成独立函数 RST_GPIO_Init(),
     放在 gpio.c 的 USER CODE BEGIN 2 之后, 由 main.c 调用
     ★ 绝对不要再写回 MX_GPIO_Init() 函数体, 否则下次
       CubeMX 生成又会被清掉 (本轮就是这么丢的)
  3. 补 MX_TIM_Encoder_Start() × 3 和 HAL_TIM_PWM_Start() × 3
  4. control_loop.c 里 loop_count++
  5. 角度改为 (cnt - zero_offset) 形式, 零点在归零后写入
  6. adc.c:79 Rank3 改成 ADC_CHANNEL_5

必须回 CubeMX 的:

  7. ADC 改连续转换 + 采样时间 239.5 周期
  8. CAN 按 APB1=36MHz 重算预分频以得到 1Mbps
  9. TIM2 编码器移到 PA15/PB3 并应用部分重映射
  10. PWM 频率提到 16-20kHz, 重定 PSC/ARR
  11. 加 IWDG

最后才是控制算法, 且电流限幅与指令超时必须和 PID 一起写,
不能事后补。
