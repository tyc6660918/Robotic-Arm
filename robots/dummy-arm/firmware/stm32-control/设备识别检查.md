# 设备识别检查 - 快速指南

## 🔍 Step 1：检查设备管理器

### 打开设备管理器
```
方法1: 按 Win + X → 选择 "设备管理器"
方法2: 右键 "此电脑" → "管理" → "设备管理器"
方法3: 按 Win + R → 输入 devmgmt.msc → 回车
```

---

## 📋 Step 2：检查 CH340 串口

### 找到 "端口(COM 和 LPT)"
展开后应该看到：
```
✅ USB-SERIAL CH340 (COMx)  ← 记住这个端口号
```

### 示例：
```
端口(COM 和 LPT)
 ├─ 通信端口 (COM1)
 └─ USB-SERIAL CH340 (COM3)  ← 这就是你的串口
```

### ⚠️ 如果没有看到
```
原因：CH340 驱动未安装
解决：
1. 找到文件：docs/WHEELTEC 直流电机附送资料/.../CH340驱动.rar
2. 解压并安装
3. 重新插拔 CH340 USB
4. 再次检查设备管理器
```

---

## 📋 Step 3：检查 DAP 下载器

### 找到 "通用串行总线控制器"
展开后应该看到类似：
```
✅ CMSIS-DAP v2
或
✅ CMSIS-DAP Debugger
或
✅ DAPLink CMSIS-DAP
```

### ⚠️ 如果看到黄色感叹号或者没有
```
原因：DAP 驱动未安装
解决：使用 Zadig 工具安装 WinUSB 驱动

步骤：
1. 下载 Zadig: https://zadig.akeo.ie/
2. 打开 Zadig.exe
3. 菜单 Options → List All Devices
4. 下拉菜单选择你的 DAP 设备（CMSIS-DAP 或 DAPLink）
5. 驱动选择 WinUSB (v6.x.x.x)
6. 点击 "Install Driver" 或 "Replace Driver"
7. 等待安装完成
8. 重新插拔 DAP
```

---

## 📋 Step 4：检查野火板

### 野火板上的 LED 应该：
```
✅ 电源 LED 亮（红色或绿色）
✅ 可能有其他 LED 闪烁（程序运行中）
```

### ⚠️ 如果 LED 不亮
```
检查：
1. USB 线是否插好
2. USB 线是否是数据线（不是只能充电的线）
3. 换个 USB 口试试
4. 检查板子上的电源开关是否打开
```
