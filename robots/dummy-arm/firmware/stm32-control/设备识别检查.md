## 使用说明

### 步骤一：打开设备管理器

启动 Windows 设备管理器的可选方法：
```
方法 1：按 Win + X 组合键 → 选择 "设备管理器"
方法 2：右键 "此电脑" → 选择 "管理" → 进入 "设备管理器"
方法 3：按 Win + R 组合键 → 输入 devmgmt.msc → 按回车键
```

---

### 步骤二：检查 CH340 串口转换器

在设备管理器中定位 "端口(COM 和 LPT)" 分类，展开后应显示：
```
USB-SERIAL CH340 (COMx)
```
其中 `COMx` 为实际分配的端口号，需记录该端口号供后续使用。

**示例输出：**
```
端口(COM 和 LPT)
 ├─ 通信端口 (COM1)
 └─ USB-SERIAL CH340 (COM3)  ← 此为 CH340 转换器对应的串口
```

**异常处理：** 若未显示上述设备，可能原因为 CH340 驱动程序未安装。
处置流程：
1. 定位驱动程序文件：`docs/WHEELTEC 直流电机附送资料/.../CH340驱动.rar`
2. 解压归档文件并执行驱动安装程序
3. 重新插拔 CH340 转换器的 USB 接口
4. 重新打开设备管理器进行确认

---

### 步骤三：检查 DAP 下载器（CMSIS-DAP）

在设备管理器中定位 "通用串行总线控制器" 分类，展开后应显示以下任一设备：
```
CMSIS-DAP v2
或
CMSIS-DAP Debugger
或
DAPLink CMSIS-DAP
```

**异常处理：** 若设备显示黄色感叹号或未被识别，可能原因为 DAP 驱动程序未正确安装。
处置流程（使用 Zadig 工具安装 WinUSB 驱动）：
1. 下载 Zadig 工具：访问 https://zadig.akeo.ie/
2. 运行 `Zadig.exe` 程序
3. 进入菜单 Options → 勾选 List All Devices
4. 在下拉菜单中选择目标 DAP 设备（CMSIS-DAP 或 DAPLink）
5. 驱动选择 WinUSB (v6.x.x.x)
6. 点击 "Install Driver" 或 "Replace Driver" 按钮
7. 等待驱动安装完成
8. 重新插拔 DAP 设备

---

### 步骤四：检查野火 STM32 开发板

开发板上电后，LED 指示灯应满足以下状态：
```
电源 LED 点亮（红色或绿色，取决于具体板型）
可能存在其他 LED 闪烁现象（表明用户程序正在执行）
```

**异常处理：** 若 LED 均未点亮，按以下顺序排查：
1. 确认 USB 线缆已牢固插入
2. 确认 USB 线缆为数据线缆（非仅充电线缆）
3. 更换其他 USB 接口重试
4. 检查开发板上的电源开关是否处于开启位置

---

### 检查完成判定标准

设备识别检查通过需满足以下全部条件：
```
1. CH340 串口号已明确记录：COM__
2. 设备管理器中可正常识别 CMSIS-DAP 设备：是/否
3. 野火板电源 LED 已点亮：是/否
```

---

### 确认无误后的后续操作

设备识别检查通过后，可按以下顺序开展后续工作：
1. 执行 CubeMX 工程配置（预计 5 分钟）
2. 执行 Keil 工程编译（预计 3 分钟）
3. 执行固件烧录（预计 1 分钟）
4. 执行串口通信测试（预计 2 分钟）

---

## 风险与局限

- 若使用非原厂 USB 线缆，可能出现供电不足或通信不稳定现象
- 部分 USB 3.0 接口对部分 DAP 下载器存在兼容性问题，出现异常时可更换至 USB 2.0 接口重试
- Windows 驱动程序数字签名验证可能阻止未经签名的驱动安装，需按系统提示执行相应处置

## 后续建议

- 建议对设备管理器截图存档，以便后续问题排查
- 建议将确认后的 COM 端口号记录在测试日志中，避免后续重复查询
- 若设备反复出现识别失败情况，建议更换备用线缆或 USB 接口
