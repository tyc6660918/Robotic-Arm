## 使用说明

### 一、操作前必须遵守的安全规范

#### 风险识别：可能导致硬件损坏的操作

1. **电源反接**：电源正负极连接错误
2. **短路故障**：裸露导线相互接触
3. **过压损坏**：12V 电源误接入 3.3V / 5V 引脚
4. **电机堵转过载**：电流过载导致驱动板烧毁
5. **带电热插拔**：通电状态下插拔连接线缆

#### 无硬件损坏风险的操作场景

- 仅连接 DAP 下载器
- 仅连接 CH340 串口模块
- 仅使用 USB 供电进行测试
- 先断电后执行接线操作
- 未连接电机驱动板

---

### 二、硬件清单确认

#### 测试阶段必需设备
- [ ] 野火霸道开发板（STM32F103ZET6）
- [ ] DAP 下载器（CMSIS-DAP）或 ST-Link V2
- [ ] CH340 USB-UART 模块
- [ ] USB 数据线 × 3（分别连接 DAP、CH340、野火板）
- [ ] 杜邦线若干（公对母、母对母规格）

#### 电机测试阶段可选设备
- [ ] WHEELTEC 直流电机 × 3（带编码器）
- [ ] TB6612 驱动板 × 2
- [ ] 12V 电源适配器（额定电流 3A 以上）
- [ ] 万用表（用于电压测量，防止接线错误）

---

### 三、强制安全操作规则

#### 接线安全规则
1. **断电操作要求**：所有接线操作必须在完全断电状态下进行
2. **接线后检查要求**：接线完成后使用万用表进行导通与绝缘检查，确认无误后方可上电
3. **渐进式测试要求**：先完成 MCU 独立测试，再逐步接入电机等外围设备
4. **小功率起始要求**：电机测试阶段 PWM 占空比从 50 起始，逐步递增
5. **应急断电准备**：上电测试期间，操作人员需保持手部置于电源开关附近，以备随时断电

#### 禁止操作项
1. **禁止带电插拔**：通电状态下不得插拔任何连接线缆
2. **禁止带电接线**：接线操作必须在断电状态下执行
3. **禁止引脚错接**：12V 电源严禁接入 3.3V / 5V 引脚
4. **禁止短路风险**：裸露导线必须使用热缩管进行绝缘包裹
5. **禁止带载启动**：电机首次测试必须在空载状态下进行

---

### 四、建议准备的辅助工具

1. **拍照记录设备**：每次接线变更后拍照存档，便于后续检查
2. **标签标识材料**：为线缆添加标识（红=12V，黑=GND，黄=信号）
3. **万用表**：用于电压与通断测量，排查接线错误
4. **独立电源开关**：桌面部署独立断电开关，便于紧急断电操作

### 五、三阶段测试安全策略

#### 阶段 1：MCU 基础测试（安全等级：无风险）
```
验证目标：MCU 正常启动，串口通信功能正常
硬件配置：仅 DAP + CH340 + USB 供电
风险等级：无硬件损坏风险
预计耗时：30 分钟
```

#### 阶段 2：编码器测试（安全等级：极低风险）
```
验证目标：编码器读数功能正常
硬件配置：追加编码器信号线（3.3V 供电）
风险等级：极低（编码器仅 3.3V 供电，无过载风险）
预计耗时：20 分钟
```

#### 阶段 3：电机测试（安全等级：中等风险）
```
验证目标：电机可实现低速转动
硬件配置：追加 12V 电源 + TB6612 驱动板 + 电机
风险等级：中等（需严格执行接线检查，从低功率开始测试）
预计耗时：40 分钟
```

### 六、阶段 1 详细安全操作流程

#### 阶段 1 操作前设备确认
需准备的设备：
```
野火霸道开发板
DAP 下载器
CH340 USB-UART 模块
USB 线缆 × 3
杜邦线 4-6 根
```

暂不使用的设备：
```
电机（不连接）
驱动板（不连接）
12V 电源（不连接）
编码器（不连接）
```

#### 接线操作流程（阶段 1）

**重要提示：全程断电操作**

##### 第 1 步：断开全部电源
```
□ 拔除野火板 USB 线缆
□ 拔除 DAP 设备 USB 线缆
□ 拔除 CH340 模块 USB 线缆
```

##### 第 2 步：连接 DAP 下载器

在野火板上定位 **SWD 接口**（通常为 4pin 或 5pin 排针，引脚定义：SWDIO、SWCLK、GND、3.3V）

| DAP 引脚 | 野火板 SWD 引脚 | 推荐线缆颜色 |
|---------|---------------|------------|
| SWDIO | SWDIO | 蓝色 |
| SWCLK | SWCLK | 绿色 |
| GND | GND | 黑色 |
| 3.3V | 不连接 | - |

**连接后检查清单：**
```
□ SWDIO 引脚对应连接正确
□ SWCLK 引脚对应连接正确
□ GND 引脚对应连接正确
□ 无线缆悬空或误触其他引脚
□ 接线状态拍照存档
```

##### 第 3 步：连接 CH340 串口模块

在野火板上定位 **USART1 接口**（引脚定义：PA9=TX1，PA10=RX1，GND）

| CH340 引脚 | 野火板引脚 | 推荐线缆颜色 | 注意事项 |
|-----------|-----------|------------|---------|
| TXD | PA10 (RX1) | 黄色 | 交叉连接 |
| RXD | PA9 (TX1) | 橙色 | 交叉连接 |
| GND | GND | 黑色 | - |
| VCC | 不连接 | - | CH340 通过 USB 端口供电 |

**连接后检查清单：**
```
□ CH340 TXD 已连接 PA10（交叉连接）
□ CH340 RXD 已连接 PA9（交叉连接）
□ GND 引脚对应连接正确
□ VCC 引脚未连接
□ 无误接其他引脚
□ 接线状态拍照存档
```

##### 第 4 步：最终验证检查

**万用表验证（推荐但非必需）：**
```
□ DAP 设备 GND 与野火板 GND 导通
□ CH340 模块 GND 与野火板 GND 导通
□ 无意外短路（万用表蜂鸣档测量任意两根信号线，不应发出蜂鸣）
```

**目视检查：**
```
□ 全部线缆插接牢固
□ 无裸露导线相互接触
□ 无线缆悬空
□ 接线状态拍照存档
```

##### 第 5 步：上电操作（按指定顺序）

1. **先连接野火板 USB 线缆**（开发板上电，指示灯应点亮）
2. **再连接 DAP 设备 USB 线缆**（连接至开发主机）
3. **最后连接 CH340 模块 USB 线缆**（连接至开发主机）

## 风险与局限

### 固件安全机制现状提示

当前固件版本**缺乏软件层面的电机保护机制**：无电流限幅、无堵转检测、无指令超时、无看门狗、无软件紧急停止功能，且 `Error_Handler` 异常处理函数不会关闭 PWM 输出。

**阶段 3（电机测试）前唯一可靠的保护措施为物理断电开关。** 建议串联物理断电开关，并优先使用具备限流功能的实验电源。

### 阶段 1 完成确认标准

满足以下全部条件可判定阶段 1 接线完成：
```
野火板电源 LED 已点亮
DAP 设备连接正常（设备管理器显示 CMSIS-DAP）
CH340 模块已识别并显示 COM 端口号
```
