## 使用说明

### 一、硬件清单

#### 必需硬件
- 野火霸道开发板（STM32F103ZET6）
- WHEELTEC 直流电机 × 3（带 GMR 编码器）
- TB6612 双路电机驱动模块 × 2（或 TB6612FNG 驱动板）
- USB-UART 转换器（CP2102 或 CH340）
- ST-Link V2 下载器
- 12V 电源（推荐额定电流 3A 以上）
- 杜邦线若干

#### 可选硬件
- INA180A1 电流检测模块 × 3
- 4 位拨码开关（用于设置 CAN ID）
- 按键 × 2
- LED × 4

---

### 二、第一部分：基础测试接线（最小系统）

**测试目标：** 验证 MCU 工作状态与串口通信功能。本阶段不连接电机，仅进行 MCU 与串口通信测试。

#### 1. ST-Link 烧录器连接

| ST-Link 引脚 | STM32F103ZET6 引脚 | 说明 |
|-------------|-------------------|------|
| SWDIO | PA13 | 数据线 |
| SWCLK | PA14 | 时钟线 |
| GND | GND | 地线 |
| 3.3V | 3.3V | 供电（可选） |

**注意：**
- 野火霸道板通常设有专用 SWD 接口，可直接插接 ST-Link
- 若开发板采用独立供电方案，则 ST-Link 的 3.3V 引脚可不予连接

#### 2. USB-UART 串口连接（调试控制台）

| USB-UART 引脚 | STM32 引脚 | 说明 |
|----------|-----------|------|
| TXD | PA10 (USART1_RX) | 交叉连接 |
| RXD | PA9 (USART1_TX) | 交叉连接 |
| GND | GND | 公共地 |

**注意：**
- TXD 与 RXD 需交叉连接（发送端接接收端，接收端接发送端）
- 野火板通常集成 CH340 USB 转串口芯片，可直接通过 USB 线缆连接上位机
- 若使用板载串口，则无需外接 USB-UART 转换器

#### 3. 供电方案

**方式 1：USB 供电（测试场景）**
- 野火板通过 USB 线缆连接上位机
- 该方案仅为 MCU 提供工作电源，**不可用于驱动电机**

**方式 2：外部电源（实际运行场景）**
- 12V DC 电源接入开发板电源接口
- 接入时需确认电源正负极

### 三、第二部分：完整接线（含电机驱动）

#### 系统拓扑结构
```
[12V 电源]
    ├─→ [STM32 开发板] ─→ [ST-Link 下载]
    │       ├─→ [USB-UART 调试]
    │       └─→ [GPIO 控制]
    │               ↓
    └─→ [TB6612 驱动 #1] ─→ [电机 0: Pitch]
    │       ├─→ [电机 1: 上夹]
    │       └─→ [编码器接 STM32]
    │
    └─→ [TB6612 驱动 #2] ─→ [电机 2: 下夹]
            └─→ [编码器接 STM32]
```

| BIN1 | PB5 | 方向控制 1 |

#### 5. 电机与编码器连接

##### 电机 0 — Pitch（俯仰）

**电机相线：**

| TB6612 #1 输出 | 电机线 | 说明 |
|---------------|--------|------|
| MOTORA+ | 红线 | 电机正极 |
| MOTORA- | 黑线 | 电机负极 |

**编码器信号线：**

| 编码器线 | STM32 引脚 | 信号 |
|---------|-----------|------|
| A 相（黄） | PA6 (TIM3_CH1) | 编码器 A |
| B 相（绿） | PA7 (TIM3_CH2) | 编码器 B |
| VCC（红） | 5V | 编码器供电 |
| GND（黑） | GND | 地 |

##### 电机 1 — 上夹（Upper Jaw）

**电机相线：**

| TB6612 #1 输出 | 电机线 | 说明 |
|---------------|--------|------|
| MOTORB+ | 红线 | 电机正极 |
| MOTORB- | 黑线 | 电机负极 |

**编码器信号线：**

| 编码器线 | STM32 引脚 | 信号 |
|---------|-----------|------|
| A 相（黄） | **PD12** (TIM4_CH1) | 编码器 A（参见下方说明） |
| B 相（绿） | **PD13** (TIM4_CH2) | 编码器 B（参见下方说明） |
| VCC（红） | 3.3V | 编码器供电（参见文末供电警告） |
| GND（黑） | GND | 地 |

**注意：** TIM4 在当前代码中已执行完全重映射
（`control/Core/Src/tim.c:369-377`，`__HAL_AFIO_REMAP_TIM4_ENABLE()`），
通道对应引脚为 **PD12/PD13**，而非原始文档标注的 PB6/PB7。若按照 PB6/PB7 接线，编码器将无法正常计数。

##### 电机 2 — 下夹（Lower Jaw）

**电机相线：**

| TB6612 #2 输出 | 电机线 | 说明 |
|---------------|--------|------|
| MOTORA+ | 红线 | 电机正极 |
| MOTORA- | 黑线 | 电机负极 |

**编码器信号线：**

| 编码器线 | STM32 引脚 | 信号 |
|---------|-----------|------|
| A 相（黄） | **PA0** (TIM2_CH1) | 编码器 A（参见下方说明） |
| B 相（绿） | **PA1** (TIM2_CH2) | 编码器 B（参见下方说明） |
| VCC（红） | 3.3V | 编码器供电（参见文末供电警告） |
| GND（黑） | GND | 地 |

**警告：引脚已更正，此处存在未解决的设计冲突**

当前代码中 TIM2 编码器对应引脚为 **PA0/PA1**
（`control/Core/Src/tim.c:325-331`），**未**应用 Partial Remap，
因此 PA15/PB3 引脚处于空闲状态，未被使用。

设计冲突：**PA0 在野火板上为 WK_UP 按键复用引脚**，`CubeMX工程配置指南.md`
亦明确标注"PA0 不分配任何外设"。该配置导致编码器与板载按键共用同一引脚。

**解决方案（二选一，不可混合使用）：**
- **修改代码（推荐方案，符合原设计）**：在 CubeMX 中将 TIM2 配置为 Partial Remap
  → PA15/PB3，重新生成代码后按照 PA15/PB3 进行接线（需禁用 JTAG，该操作已在
  `stm32f1xx_hal_msp.c` 中完成）
- **修改接线**：沿用 PA0/PA1 引脚配置，并确认板载 WK_UP 按键不会造成干扰（需断开按键跳线）

**警告：** 此外，**PA0/PA1 同时为 ADC 输入引脚（ADC12_IN0/IN1）**，该类模拟引脚在
STM32F103 芯片上通常**不具备 5V 容忍能力**。若编码器按照原始文档采用 5V 供电，其 A/B 输出
直接接入 PA0/PA1 存在过压损坏风险。接线前请查阅 STM32F103ZET6 数据手册确认该引脚的
5V 容忍（FT）属性。

#### 6. LED 指示灯（可选配置）

| LED 标识 | STM32 引脚 | 功能说明 |
|---------|-----------|---------|
| LED_P | PE2 | Pitch 电机状态指示 |
| LED_U | PE3 | 上夹电机状态指示 |

**接线方式：**
```
STM32 引脚 → 限流电阻 (220Ω) → LED 正极 → LED 负极 → GND
```

| 按键标识 | STM32 引脚 | 功能说明 |
|---------|-----------|---------|
| BTN1 | PE0 | 功能按键 1 |
| BTN2 | PE1 | 功能按键 2 |

**接线方式：**
```
STM32 引脚 → 按键 → GND（采用内部上拉配置，按下时引脚接地）
```

#### 8. 拨码开关（可选配置，用于设置 CAN ID）

| 拨码位 | STM32 引脚 | 说明 |
|--------|-----------|------|
| DIP1 | PC0 | Bit 0 |
| DIP2 | PC1 | Bit 1 |
| DIP3 | PC2 | Bit 2 |
| DIP4 | PC3 | Bit 3 |

**接线方式：** 每个引脚连接拨码开关一端，开关另一端接地。

#### 9. 电流检测（可选配置，INA180A1 模块）

**INA180 输出信号与 STM32 引脚对应关系：**

| INA180 输出通道 | STM32 引脚 | 说明 |
|------------|-----------|------|
| Pitch 电流 | PA4 (ADC1_CH4) | Pitch 电机电流采样 |
| 上夹电流 | PA5 (ADC1_CH5) | 上夹电机电流采样 |
| 下夹电流 | PA3 (ADC1_CH3) | 下夹电机电流采样 |

**注意：**
- INA180 模块需串联接入电机回路
- 分流电阻规格：0.1Ω
- 放大器增益：20V/V

### 四、第三部分：接线检查清单

#### 烧录前检查项
- [ ] ST-Link 连接正确（SWDIO、SWCLK、GND）
- [ ] USB-UART 连接正确（TX 与 RX 交叉连接）
- [ ] 野火板供电正常（USB 或 12V 外部电源）

#### 电机驱动检查项
- [ ] TB6612 电源接线正确（VM=12V，VCC=5V，GND 公共连接）
- [ ] PWM 信号线连接完成（PA8、PC6、PC7）
- [ ] 方向控制线连接完成（PB0/1、PB5/12、PB13/14）
- [ ] STBY 引脚已接 5V（驱动使能）

#### 编码器检查项
- [ ] 编码器 A/B 相连接正确
- [ ] 编码器供电连接正确（VCC 与 GND）
- [ ] 编码器引脚与**代码实际定义**一致：Pitch=PA6/PA7、上夹=PD12/PD13、
      下夹=PA0/PA1（若改用 PA15/PB3 方案需同步修改代码）
- [ ] 编码器供电电压已确认（设计方案要求 3.3V，非 5V）
- [ ] 若沿用 PA0/PA1 方案：已确认板载 WK_UP 按键不产生冲突

#### 电机检查项
- [ ] 电机相线连接牢固（红/黑线）
- [ ] 电机未发生卡死，可通过手动方式转动
- [ ] 三个电机对应关系正确（Pitch=TIM3，上夹=TIM4，下夹=TIM2）

### 五、第四部分：分步测试流程

#### 阶段 1：MCU 基础测试（不连接电机）
```
验证目标：MCU 工作状态与串口通信功能正常
接线配置：仅 ST-Link + USB-UART
测试方法：烧录固件，打开串口终端，输入 help 命令
```

#### 阶段 2：编码器测试（不连接驱动板）
```
验证目标：编码器读数功能正常
接线配置：追加编码器信号线
测试方法：串口输入 enc 0、enc 1、enc 2 命令，手动转动电机观察计数值变化
```

#### 阶段 3：驱动板测试（空载状态）
```
验证目标：PWM 输出与方向控制功能正常
接线配置：追加 TB6612 控制信号（不连接电机）
测试方法：串口输入 pwm 0 100 命令，使用示波器测量 PA8 引脚输出波形
```

#### 阶段 4：电机测试（带载状态）
```
验证目标：电机可实现低速转动
接线配置：追加电机相线
测试方法：串口输入 pwm 0 50 命令，观察电机转动状态
```

#### 阶段 5：完整系统测试
```
验证目标：闭环控制功能正常
接线配置：全部接线完成
测试方法：依次测试位置模式、速度模式、力矩模式
```

## 风险与局限

### 安全操作警告

#### 接线过程
1. **断电操作要求**：所有接线操作必须在断电状态下进行
2. **极性检查要求**：确认 12V 电源正负极、LED 正负极连接正确
3. **短路防护要求**：裸露线头使用热缩管进行绝缘包裹

#### 首次上电阶段
1. **温升检查要求**：上电后立即检查 TB6612 芯片温度，不应出现异常发热
2. **电压检查要求**：使用万用表测量 5V 与 12V 电源输出，确认数值正常
3. **应急断电准备**：操作人员需保持手部置于电源开关附近，以备随时断电

#### 电机测试阶段
1. **渐进式加载要求**：PWM 占空比从 50 起始，逐步递增
2. **空载测试要求**：先进行未装配机械臂状态下的电机空转测试
3. **电流监测要求**：电流超过 2A 时立即停止测试
