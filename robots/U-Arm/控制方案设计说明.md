# U-Arm 主臂控制接口方案

## 1. 区域功能定位（功能定位）

本模块承担遥操作系统主臂控制接口的实现任务。U-Arm 作为人工输入装置，由操作人员手动操控以驱动从属机械臂。其通过 7 通道舵机系统（6 个关节 + 1 个夹爪/扳机）提供增量式关节位置反馈，支持在无需精确主臂运动学模型的条件下实现主从遥操作。系统支持三种控制模式：直接关节映射、带相对 SE(3) 位姿映射的增量式笛卡尔控制、以及带逆运动学求解的末端执行器位姿控制。

## 6. 使用说明（使用说明）

### Master Arm (ServoReader) API（主臂接口）

```python
from uarm import ServoReader

# Initialize with serial port (Feetech: 1 Mbps, Generic: 115200)
reader = ServoReader(port='/dev/ttyUSB0', baudrate=1000000)

# Get 7-element array of joint angle offsets (degrees) from zero calibration
# Returns: [J1_offset, J2_offset, J3_offset, J4_offset, J5_offset, J6_offset, gripper_offset]
action_offset = reader.get_action_offset()

# Publish to ROS topic (if using ROS integration)
# Topic: /servo_angles, Rate: 50-100 Hz
```

### Slave Arm Control Examples（从臂控制示例）

**xArm7（ROS 方案，20 Hz）：**
```python
# Set 6 joint targets (angles in degrees or radians)
arm.set_servo_angle(angle=[j1, j2, j3, j4, j5, j6], speed=50, is_radian=False)

# Control gripper separately
arm.set_gripper_position(position=800, speed=2000)  # position: 0-850

# Enable servo mode
arm.motion_enable(enable=True)
arm.set_mode(6)  # mode 6 = servo control
```

**ARX5（CAN 方案，200 Hz）：**
```python
from arx5_interface import JointState

# Send joint position + velocity + gripper command
joint_state = JointState()
joint_state.pos = [j1, j2, j3, j4, j5, j6]  # radians
joint_state.vel = [v1, v2, v3, v4, v5, v6]  # rad/s
joint_state.gripper = gripper_pos  # 0.0-1.0
arm.set_joint_cmd(joint_state)

# Velocity limits enforced: 1.2 rad/s (J1-J3), 2.0 rad/s (J4-J6)
```

**Dobot CR5（ROS 方案，10 Hz）：**
```python
# Servo mode with gain control
arm.move_arm_to_joint_angles_servo(angles=[j1, j2, j3, j4, j5, j6], t=0.1, gain=250)

# Standard move (blocking)
arm.move_arm_to_joint_angles(angles=[j1, j2, j3, j4, j5, j6], wait=True)
```

### Control Modes（控制模式）

**模式一：关节空间控制（直接映射）**
- 将主臂关节角度直接映射至从臂关节
- 要求主从臂具备相似的运动学结构
- 应用场景：xlerobot_teleop.py、so100_teleop.py

**模式二：增量式笛卡尔控制（相对 SE(3)）**
- 主臂通过 get_action_offset() 提供关节偏移量
- PC 端计算主臂正运动学 → 相对位姿增量
- 将增量映射至从臂：T_slave_target = T_slave_ref + scale × (T_master - T_master_ref)
- 离合器机构支持无跳变回零操作
- 优势：无需主臂 URDF，支持不同臂型尺寸

**模式三：末端执行器位姿控制（PD EE Pose）**
- 配合逆运动学求解器实现直接笛卡尔空间控制
- 支持增量（delta）动作或绝对位姿目标
- 参考系选项：root_translation、body_translation、body_aligned_rotation
- 逆运动学求解器支持热启动以加速收敛

### Safety Configuration（安全配置）

- One-Euro 滤波器：min_cutoff = 1.65 Hz，beta = 0.01
- 速度限制：线速度 0.08 m/s，角速度 0.8 rad/s
- 加速度限制：线加速度 0.35 m/s²，角加速度 3.0 rad/s²
- 超时保护：主/从臂反馈超时阈值 50–100ms
- 状态机：IDLE → READY → TELEOP → HOLD → FAULT

## 7. 风险与限制（风险与局限）

| Feetech driver writes servo EPROM on startup | High | Lines 29-60 of feetech_servo_reader.py write calibration offsets to servo flash memory | Disable EPROM write operations, use external YAML calibration file for zero-point storage |

| IK convergence on real hardware may differ from simulation | Medium | Simulation achieves 100% success with bounded solver (max_nfev=15), but cable dynamics and friction not modeled | Test with hot-start IK solver, implement fallback strategies if convergence fails |
| Communication latency over 100ms could cause instability | High | Target <100ms specified but never measured - USB serial + IK computation + slave arm communication | Measure end-to-end latency once hardware available, may need optimized IK or predictive filtering |
| Cumulative drift in long operations | Medium | Incremental control accumulates small errors over time | Implement periodic re-capture when clutch button pressed, or drift correction based on visual feedback |
| Gripper control protocol not defined for Dummy ASCII interface | Medium | Dummy firmware supports MoveJ/MoveL but no gripper command documented | Extend firmware ASCII protocol with gripper commands (e.g., "G <position>") or use separate CAN channel |
