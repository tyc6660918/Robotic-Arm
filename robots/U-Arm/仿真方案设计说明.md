# U-Arm 主臂仿真与模型系统

## 1. 区域功能定位（功能定位）

本方案提供 U-Arm 主设备遥操作系统的仿真基础设施与运动学模型。其采用 ManiSkill 3.0.0b21 实现基于物理引擎的机器人仿真，提供双模式（CPU/GPU）逆运动学与正运动学求解器，并定义末端执行器位姿控制的控制器架构。当前模块包含参考机器人实现（Panda、xArm7、Fetch）及框架代码，但尚缺乏针对 U-Arm Config1/2/3 硬件变体（在遥操作系统中担任主设备角色）的 URDF 模型与智能体实现。

## 4. 已完成功能（已完成功能）

- **ManiSkill 3.0.0b21 仿真框架**：基于 SAPIEN 3.0.1 构建的生产级物理仿真，包含 74 个示例脚本与广泛的机器人覆盖范围
- **双模式运动学求解器**：CPU 模式采用 Pinocchio 实现 URDF 解析与逆运动学求解（最大迭代次数 100）；GPU 模式采用 pytorch-kinematics 实现伪逆逆运动学与面向实时控制的快速雅可比增量 IK
- **分层控制器架构**：基础 PDJointPosController 负责关节空间控制；PDEEPosController/PDEEPoseController 通过逆运动学实现末端执行器笛卡尔控制，支持可配置的刚度/阻尼/力限制参数
- **参考机器人智能体模式**：各机器人（Panda、xArm7、Fetch）均实现 BaseAgent 接口，包含 URDF 路径、关键帧、关节名称列表、控制器配置、tcp_pose 暴露、抓取检测及多种控制模式
- **实物硬件串口接口**：ServoReader 类通过串口（1 Mbps）与 Feetech 舵机通信，读取 7 路舵机位置，结合标定偏移量实现 PWM 至角度的转换
- **遥操作集成设计**：U臂与Dummy臂法兰接口实现说明.md 规定基于 PC 的遥操作控制器方案，流程为 U-Arm 正运动学 → 相对位姿映射 → Dummy 逆运动学 → 关节指令，并配备安全状态机（DISABLED/ARMED/ACTIVE/HOLD/FAULT）
- **综合 URDF 模型库**：80+ 模型覆盖机械手（Allegro、Inspire）、机械臂（Panda、xArm、Fetch）及人形机器人（G1），作为实现参考

## 6. 使用说明（使用说明）

**体系架构**：本方案采用 ManiSkill 3.0.0b21 作为核心仿真框架，底层依托 SAPIEN 3.0.1 物理引擎。运动学层提供双模式 IK/FK 能力：CPU 模式采用 Pinocchio 实现 URDF 解析、关节排序与逆运动学求解（最大迭代 100 次）；GPU 模式采用 pytorch-kinematics 实现伪逆 IK 与面向实时控制的快速雅可比增量 IK。控制器采用分层设计：基础 PDJointPosController 负责关节空间控制；PDEEPosController/PDEEPoseController 通过逆运动学实现末端执行器笛卡尔控制。

**机器人智能体模式**：各机器人（Panda、xArm7、Fetch）均为已注册的 BaseAgent 实例，包含 URDF 路径、关键帧、关节名称列表、控制器配置（刚度/阻尼/力限制）及可选传感器。智能体暴露 tcp_pose 接口，实现抓取检测（is_grasping），并配置多种控制模式（pd_joint_pos、pd_ee_delta_pose 等）。80+ URDF 文件覆盖机械手（Allegro、Inspire）、机械臂（Panda、xArm、Fetch）及人形机器人（G1）。

**实物硬件集成**：与仿真环境独立，uarm/ ROS 包负责实物硬件控制：ServoReader 通过串口（1 Mbps）与 Feetech 舵机通信，读取 7 路舵机位置，结合标定偏移量实现 PWM 至角度转换。针对 xArm（servo2xarm.py）、Dobot（servo2Dobot.py）、ARX（arx_teleop.py）及 LeRobot 变体均提供对应脚本。U臂与Dummy臂法兰接口实现说明.md 规定基于 PC 的遥操作控制器架构：U-Arm 正运动学 → 相对位姿映射 → Dummy 逆运动学 → 关节指令，并配备安全状态机（DISABLED/ARMED/ACTIVE/HOLD/FAULT）。

**仿真运行**：针对 U-Arm 的专用仿真运行说明需待 URDF 与智能体实现后方可确认。参考机器人仿真可通过 ManiSkill 示例目录中的 74 个示例脚本运行。

## 8. 依赖关系（依赖项）

- **ManiSkill 3.0.0b21**：核心仿真框架，提供物理引擎集成、智能体抽象与控制器架构
- **SAPIEN 3.0.1**：物理引擎后端，支持刚体动力学、碰撞检测与接触模拟
- **pytorch-kinematics 0.7.5**：GPU 加速的正/逆运动学库，含批量伪逆求解器
- **Pinocchio**（通过 SAPIEN 封装）：基于 CPU 的运动学求解器，支持 URDF 解析与解析梯度
- **PyTorch 2.8.0 with CUDA 12.8**：pytorch-kinematics 与神经网络集成的 GPU 计算后端
- **fast_kinematics 0.2.2**：用于性能对比的替代运动学求解器
- **roboticstoolbox-python 1.1.1**：用于运动学验证的机器人算法库
- **Feetech servo SDK 1.0.0**：U-Arm 主臂的实物硬件串口通信库
- **xArm Python SDK 1.15.3**：用于 xArm 从臂测试的实物硬件集成库

## 9. 下一步计划（后续工作）

1. **采购并装配 U-Arm Config1 硬件**（优先级：高）—— 尺寸测量、舵机零位标定及 URDF 验证所需的物理基础。基于 config1.STEP 模型 3D 打印 11 个 STL 结构件，与 Feetech 舵机完成装配，测量实际 DH 参数与关节限位。

2. **创建 Config1/2/3 U-Arm 变体的 URDF 模型**（优先级：高）—— 遵循 panda_v2.urdf 结构编写 URDF 文件，包含实测 DH 参数、关节限位、碰撞几何与可视化网格。存储于 `assets/robots/uarm/` 目录。

3. **实现 U-Arm BaseAgent 子类**（优先级：高）—— 创建 `agents/robots/uarm/uarm_config1.py`（及 config2/3 变体），定义 URDF 路径、控制器配置（7 关节的刚度/阻尼参数）、关键帧（静止位姿、标定位姿）及 tcp_pose 定义。

4. **构建运动学验证测试套件**（优先级：中）—— 实现 pytest 测试集，涵盖 FK→IK→FK 往返测试（容差：位置 0.1mm，姿态 0.05°）、关节限位网格上的工作空间可达性检测、工作空间边界附近的奇异性检测。

5. **开发从仿真到实物的验证框架**（优先级：中）—— 创建脚本通过 ServoReader 读取实际舵机位置，对相同关节角计算仿真正运动学，测量位置与姿态偏差。目标：RMS 误差 <1mm（位置），<0.5°（姿态）。

6. **创建遥操作示例环境**（优先级：中）—— 实现 ManiSkill 环境，其中 U-Arm 主智能体通过 PDEEPoseController 的 delta 位姿动作控制 Dummy 从智能体。展示 U臂与Dummy臂法兰接口实现说明 中定义的 SE(3) 增量映射策略。

7. **集成硬件标定管线**（优先级：低）—— 建立 Feetech 舵机零位偏移 → URDF 关节原点参数 → 仿真验证的数据流转通道。标数据变更时实现 URDF 的自动化重新生成。
