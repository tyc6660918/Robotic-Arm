## 📊 关键发现

### 项目概况
```
OpenRST = Open Robotic Surgical Tool
类型: 线缆驱动的模块化手术机械臂
特点: 3D打印制造、可定制、开源
```

### 三大模块关系
```
┌─────────────────┐
│   驱动单元      │  ← 3个电机 + 减速器
│  (Drive Unit)   │     将旋转转为牵引力
└────────┬────────┘
         │ 线缆传递
┌────────▼────────┐
│   接口模块      │  ← 鼓轮 + 滑轮组
│(Interface Module)│    路径转换 + 快换
└────────┬────────┘
         │ 线缆传递
┌────────▼────────┐
│  末端执行器     │  ← 3自由度运动
│ (End Effector)  │     俯仰/偏航/开合
└─────────────────┘
```

### 电机尺寸对比
```
Maxon RE10:    Ø10mm  × ~30mm  = 15g
MG513P10:      Ø36.6mm × 75mm  = 70g

体积增大: ~30倍
重量增加: ~5倍
```
