## 一、零件清单与分类

### 1. 核心动力系统 (Motor & Actuation)

#### 1.1 电机本体
- **motor_base.SLDPRT** (141KB)
  - 功能：固定 Maxon RE10 电机的基座
  - 尺寸：适配 Ø10mm 电机
  - 接口：与 attachment_base 螺栓连接
  - 特征：行星减速器安装接口

#### 1.2 驱动盘系统（三级联动）
- **actuation_disk_M0.SLDPRT** (369KB) - 第一级驱动盘
- **actuation_disk_M1.SLDPRT** (363KB) - 第二级驱动盘  
- **actuation_disk_M2.SLDPRT** (364KB) - 第三级驱动盘（连接电机）

**功能说明**：
```
电机输出轴 → coupling → actuation_disk_M2 
                    ↓
              actuation_disk_M1
                    ↓
              actuation_disk_M0 → 拉线传动到 end_effector
```

每个驱动盘具有：
- 中心孔（接收联轴器或前级输出）
- 外圈齿轮（啮合传动）
- 绕线槽（控制线缆路径）

#### 1.3 联轴器
- **coupling_M2_M4.SLDPRT** (89KB)
  - 功能：连接电机输出轴与 actuation_disk_M2
  - 输入端：Ø2-3mm（Maxon RE10 输出轴）
  - 输出端：与 M2 驱动盘配合
  - 固定方式：顶丝或键槽连接

## 二、快速更换机构 (Tool Exchange System)

### 2.1 释放凸轮系统
- **release_cam.SLDPRT** (100KB) - 主释放凸轮
- **release_cam_pitch.SLDPRT** (100KB) - 俯仰释放凸轮
- **release_cam_stopper.SLDPRT** (30KB) - 凸轮限位器

功能：按下 release_button 时，凸轮旋转解锁 engagement_lever

### 2.2 锁定机构
- **engagement_lever.SLDPRT** (87KB)
  - 功能：锁定或释放 interface_module 与 drive_unit 的连接
  - 工作原理：杠杆式卡扣，常态锁定
  - 操作：release_cam 驱动杠杆打开

- **release_button.SLDPRT** (144KB)
  - 功能：手动触发释放机构
  - 位置：drive_unit 侧面易操作位置
  - 机械联动：button → cam → lever → 释放

**工作流程**：
```
按压 release_button → release_cam 旋转 → 
engagement_lever 打开 → interface_module 弹出
```

## 三、结构与外壳 (Housing & Structure)

### 3.1 主体结构
- **drive_unit_base.SLDPRT** (514KB) - 最大复杂度零件
  - 功能：主承载框架
  - 特征：
    - 电机安装位
    - 驱动盘轴承座
    - 电路板固定孔
    - 接口模块对接面
  
- **attachment_base.SLDPRT** (1.1MB) - 最大文件
  - 功能：连接 drive_unit 与外部安装点
  - 特征：
    - 多方向安装孔
    - 应力分散结构
    - 可能包含减震设计

### 3.2 外壳盖板
- **drive_unit_top_cover.SLDPRT** (610KB)
  - 功能：顶部密封，保护驱动系统
  - 特征：可能有散热孔或透明观察窗
  
- **drive_unit_side_cover_a.SLDPRT** (252KB)
- **drive_unit_side_cover_b.SLDPRT** (109KB)
  - 功能：侧面保护与线缆出口
  - 区别：A/B 可能是左右对称件或不同功能区

### 3.3 线缆管理
- **cable_cap.SLDPRT** (56KB)
  - 功能：线缆出口的保护与应力消除
  - 位置：drive_unit_base 的线缆通道
  - 作用：
    - 防止线缆磨损
    - 固定线束位置
    - 防尘密封

## 五、电机更换影响分析

### 直接影响零件（需完全重新设计）

1. **motor_base.SLDPRT** 🔴
   - 孔径：Ø10mm → Ø36.6mm（MG513）
   - 固定方式：行星减速器螺纹 → 6×M3 螺栓阵列
   - 中心高：需重新计算以保持 coupling 对齐

2. **coupling_M2_M4.SLDPRT** 🔴
   - 输入孔：Ø2-3mm → Ø6mm D型轴
   - 固定方式：顶丝 → 可能需要键槽连接
   - 长度：适应新电机轴长 14mm

### 间接影响零件（需验证间隙）

3. **actuation_disk_M2.SLDPRT** 🟡
   - 检查中心孔是否需扩大
   - 验证齿轮啮合是否受影响

4. **drive_unit_base.SLDPRT** 🟡
   - 电机仓空间是否足够（Ø36.6mm vs Ø10mm）
   - 可能需要局部扩容

5. **drive_unit_*_cover** 🟡
   - 内部间隙检查
   - 可能需要外凸设计

6. **attachment_base.SLDPRT** 🟢
   - 可能无需修改，仅需验证
