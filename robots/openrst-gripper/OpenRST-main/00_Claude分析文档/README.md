## 📊 01_电机对比分析

包含电机性能对比的 JSON 数据文件：

- `motor_comparison_report.json` - Maxon RE10 vs MG513P10 详细对比

**主要发现**：
- 尺寸差异：MG513 直径是 Maxon 的 3.7 倍（36.6mm vs 10mm）
- 扭矩差异：Maxon 系统输出扭矩约 768 mNm，MG513 约 39 mNm
- 对于轻物夹取应用，MG513 性能足够

## 🔧 02_Python工具脚本

自动化分析工具，用于提取和对比数据：

### `analyze_drive_unit.py`
**功能**: 分析 SOLIDWORKS 装配体结构
- 启动 SOLIDWORKS
- 打开 drive_unit 装配体
- 提取零件清单和关系
- 识别电机相关组件

**使用方法**:
```bash
python analyze_drive_unit.py
```

### `compare_motors.py`
**功能**: 对比两个电机的规格差异
- 读取电机参数
- 生成对比表格
- 输出 JSON 报告

### `extract_motor_dimensions.py`
**功能**: 从 STEP 文件提取尺寸
- 解析 STEP 格式
- 提取关键尺寸参数
- 识别圆柱体、孔等特征

### `motor_change_analyzer.py`
**功能**: 综合分析电机更换影响
- 装配体结构分析
- 尺寸冲突检测
- 生成修改建议

### `motor_change_config.json`
**配置文件**: 包含文件路径和参数设置

## 📄 04_电机规格资料

### `MG513_specs.pdf`
**来源**: WHEELTEC 直流电机附送资料  
**内容**: MG513 系列电机的完整技术规格

**关键参数** (MG310/MG513 系列):
```
型号:       MG513P10-12V (GMR编码器版)
减速比:     1:20.409
电压:       7.4V (建议 7-13V)
额定扭矩:   0.4 Kgf·cm (0.039 Nm)
堵转扭矩:   1.5 Kgf·cm (0.147 Nm)
输出轴:     Ø6mm D型轴
安装方式:   6×M3 螺纹孔
重量:       70g
```

**外形尺寸**:
- 电机直径: Ø36.6 mm
- 减速器直径: Ø32.8 mm
- 总长度: 75.1 mm
- 安装孔分布: Ø31 mm 圆周上
