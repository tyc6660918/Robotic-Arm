## 📦 项目组成

OpenRST（Open Robotic Surgical Tool）是一个开源的模块化机械手术工具平台，采用线缆驱动机制。

### 主要目录结构

```
OpenRST-main/
├── 00_Claude分析文档/           # 本次分析生成的所有文档（中文）
├── CAD Files/                   # 3D 模型文件
│   ├── drive_unit/              # 驱动单元（16个零件）
│   ├── end_effector/            # 末端执行器（8个零件，3种夹爪）
│   └── interface_module/        # 接口模块（10个零件）
├── Control software/            # 控制软件（ROS 节点）
├── PCB/                         # 电路板设计文件
├── Sim/                         # 仿真相关
├── URDF/                        # 机器人描述文件
└── OpenRST论文.pdf              # 主要论文

总零件数: 34个零件（不含标准件和线缆）
```

## 🔧 三大核心模块

### 1. 驱动单元 (Drive Unit) - 16个零件

**功能**: 包含3个电机，将电机旋转转换为线缆牵引力

**关键零件**：

#### 电机相关（电机更换会影响）
- ✅ `motor_base.SLDPRT` - 电机安装座（**必须重新设计**）
- ✅ `coupling_M2_M4.SLDPRT` - 联轴器（**必须重新设计**）
- ✅ `actuation_disk_M0.SLDPRT` - 驱动盘 M0（可能需要修改接口）
- ✅ `actuation_disk_M1.SLDPRT` - 驱动盘 M1（可能需要修改接口）
- ✅ `actuation_disk_M2.SLDPRT` - 驱动盘 M2（可能需要修改接口）

#### 结构和外壳（尺寸可能需要调整）
- 🟡 `drive_unit_base.SLDPRT` - 驱动单元底座（电机腔体可能需要扩大）
- 🟡 `attachment_base.SLDPRT` - 附件底座（最大的结构件）
- 🟡 `drive_unit_top_cover.SLDPRT` - 顶盖（间隙检查）
- 🟡 `drive_unit_side_cover_a.SLDPRT` - 侧盖 A（间隙检查）
- 🟡 `drive_unit_side_cover_b.SLDPRT` - 侧盖 B（间隙检查）

#### 快换机构（可能不受影响）
- ⚪ `release_button.SLDPRT` - 释放按钮
- ⚪ `release_cam.SLDPRT` - 释放凸轮
- ⚪ `release_cam_pitch.SLDPRT` - 俯仰释放凸轮
- ⚪ `release_cam_stopper.SLDPRT` - 凸轮限位器
- ⚪ `engagement_lever.SLDPRT` - 锁合杆

#### 线缆管理
- ⚪ `cable_cap.SLDPRT` - 线缆盖板

**分析重点**：

- 快换机构的工作原理？

### 2. 末端执行器 (End Effector) - 8个零件

**功能**: 实现俯仰、偏航、开合三个自由度的手术器械末端

**零件清单**：

#### 基础连杆
- `ee_base_link.SLDPRT` - 末端执行器基座（连接到接口模块）
- `ee_pitch_link.SLDPRT` - 俯仰关节连杆

#### 三种可更换夹爪
1. **开窗式夹爪 (Fenestrated)** - 适合组织抓取
   - `fenestrated_jaw_link_a.SLDPRT` - 左夹爪
   - `fenestrated_jaw_link_b.SLDPRT` - 右夹爪

2. **马里兰夹爪 (Maryland)** - 精细操作
   - `maryland_jaw_link_a.SLDPRT` - 左夹爪
   - `maryland_jaw_link_b.SLDPRT` - 右夹爪

3. **持针器夹爪 (Needle Driver)** - 缝合用
   - `needle_driver_jaw_link_a.SLDPRT` - 左夹爪
   - `needle_driver_jaw_link_b.SLDPRT` - 右夹爪

**关键特性**：
- 模块化设计，可快速更换不同类型的夹爪
- 线缆驱动实现三自由度
- 3D 打印制造，易于定制

**分析重点**：
- 三个自由度如何通过线缆实现？
- 夹爪的开合角度和行程？
- 末端力传递效率？

### 3. 接口模块 (Interface Module) - 10个零件

**功能**: 连接驱动单元和末端执行器，实现线缆路径转换和工具快换

**零件清单**：

#### 线缆传动
- `driving_drum.SLDPRT` - 驱动鼓轮（缠绕线缆）
- `pulley_guide_bank.SLDPRT` - 滑轮导向组
- `cable_guide.SLDPRT` - 线缆导向器
- `disk_guide.SLDPRT` - 盘片导向器
- `interface_disk.SLDPRT` - 接口盘

#### 结构和固定
- `interface_base.SLDPRT` - 接口模块底座
- `drum_lock.SLDPRT` - 鼓轮锁定机构
- `tube_clamp.SLDPRT` - 管夹

#### 外壳
- `cover_top.SLDPRT` - 顶盖
- `cover_side.sldprt` - 侧盖

**分析重点**：
- 线缆如何从驱动单元传递到末端？
- 鼓轮的减速比和增力作用？
- 快换接口的定位精度？

## 🔄 完整传动链路

```
电机旋转
   ↓
减速器 (内置在电机中)
   ↓
联轴器 (coupling_M2_M4)
   ↓
驱动盘 (actuation_disk_M0/M1/M2)
   ↓
线缆牵引
   ↓
接口模块 (鼓轮和滑轮组)
   ↓
末端执行器 (三自由度运动)
```

**关键问题**：
1. 每个电机（M0/M1/M2）分别控制末端的哪个自由度？
2. 总减速比是多少？（电机减速器 × 其他机械减速）
3. 线缆传动的效率如何？
4. 10N 夹持力是如何计算和实现的？

## 🎯 电机更换影响分析

### 直接影响（必须修改）
```
现有电机: Maxon RE10 (Ø10mm)
新电机:   MG513P10 (Ø36.6mm)
尺寸变化: 3.7倍
```

**必须重新设计的零件**：
1. ✅ `motor_base.SLDPRT` - 安装孔从 Ø10mm → Ø36.6mm
2. ✅ `coupling_M2_M4.SLDPRT` - 轴孔从 Ø2-3mm → Ø6mm D型轴
3. ✅ 可能需要适配器来连接驱动盘

### 间接影响（需要检查）
**可能需要修改的零件**：
- 🟡 `drive_unit_base.SLDPRT` - 电机腔体空间
- 🟡 `attachment_base.SLDPRT` - 整体布局
- 🟡 所有外壳盖板 - 间隙和干涉

### 不受影响的部分
**保持不变**：
- ⚪ 末端执行器全部零件（8个）
- ⚪ 接口模块全部零件（10个）
- ⚪ 快换机构（release 系列）
- ⚪ 线缆系统

**原因**: 这些部分不直接接触电机，只要驱动盘的输出端保持不变即可。

## 📊 设计策略总结

### 方案：模块化电机适配器

**核心思路**：
1. 保留原有驱动盘（actuation_disk）
2. 保留原有末端执行器和接口模块
3. 设计新的电机安装座和联轴器
4. 最小化对原设计的影响

**需要新设计的零件**：
- 电机安装座适配器（替代 motor_base）
- 新联轴器（适配 Ø6mm D型轴）
- 可能的驱动盘适配接口

**设计约束**：
- 保持驱动盘的输出接口不变
- 保持线缆走线路径不变
- 保持快换机构功能不变
- 新电机重量（70g）对平衡的影响
