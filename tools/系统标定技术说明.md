# 系统标定与配置工具集

## 1. 区域用途

本区域提供机械臂系统调试与维护所需的标定基础设施及配置管理工具。其涵盖电机编码器标定算法、持久化参数存储、基于命令行的整定接口，以及遥操作坐标变换标定工作流。这些工具在原始硬件（未标定传感器、出厂默认参数）与可运行系统（校正后的位置反馈、整定后的控制增益、经验证的运动学）之间架起桥梁。

## 6. 使用说明

### 电机编码器标定（Dummy-35/42 电机固件）

**触发标定：**
1. 使用 simple-cli.py 通过串口（115200 波特）连接电机
2. 按下电机板上的物理按键 OR 通过命令行发送标定命令
3. 标定在 20kHz 控制环路中自动执行
4. 成功后系统重启以重新加载标定数据

**标定流程：**
- **状态机**：从 FORWARD_PREPARE 到 CALCULATING 共 7 个状态
- **采样**：200 硬步长 × 每步 16 采样，取平均以降噪
- **验证**：方向一致性、连续界（0.5-1.5× 预期增量）、单相步检测
- **输出**：闪存存储的查找表，将编码器原始角度映射到校正后的电位置
- **安全**：使用 BoardConfig_t 中可配置的 calibrationCurrent 限制

**错误检测：**
- 方向错误：检测电机是否与命令方向反向旋转
- 连续性错误：标记不连续的编码器读数
- 相步错误：验证每个机械步进对应单个电周期

### Simple 命令行工具（tools/simple-cli/）

**启动命令行：**
```bash
cd tools/simple-cli
python simple-cli.py
```

**命令：**
- `kp <motor_id> <value>` - 调整比例增益
- `ki <motor_id> <value>` - 调整积分增益
- `kd <motor_id> <value>` - 调整微分增益
- `reboot <motor_id>` - 应用新参数
- `start/stop/enable/disable` - 电机状态控制
- 按下电机上的手动按键以触发标定

**自动发现：** 扫描 COM5/COM6 或执行全端口扫描以查找控制器

### 配置备份/恢复

**备份配置：**
```python
from configuration import backup_config
backup_config(device)  # 将 JSON 导出到以序列号为键的临时目录
```

**恢复配置：**
```python
from configuration import restore_config
restore_config(device, config_dict)  # 应用前验证属性
device.save_configuration()  # 提交到持久化存储
```

**安全：** 恢复前验证设备上存在属性，缺失键报告错误

### MoveIt2 伺服配置

**安全限值（dummy_simulated_config.yaml）：**
- **命令超时**：100ms - 无新命令时停止伺服
- **速度缩放**：0.4 m/s 线性、0.8 rad/s 旋转、0.5 关节
- **奇异保护**：低阈值 17.0、硬停止 30.0、脱离乘数 2.0
- **关节限位余量**：0.1 rad 缓冲
- **碰撞检测**：10Hz 频率、0.001m 自碰撞接近距离、0.002m 场景接近距离
- **控制频率**：34ms 发布周期（~29Hz），可选低延迟模式

### 遥操作标定工作流（U-Arm → Dummy）

**阶段 1：主臂伺服标定**
1. 禁用伺服转矩
2. 定位到机械基准（可重复的装配位姿）
3. 记录各伺服的 `zero_ticks`（原始编码器值）
4. 手动旋转测试确定 `direction`（±1）
5. 多角度验证（30°、60°、90°）以确定计数-弧度比
6. **验收**：重启并验证可重复性

**阶段 2：URDF 正向运动学验证**
1. 从 STEP 装配构建 URDF（关节轴、连杆几何）
2. 应用 zero_ticks 与方向标定
3. 测量 10+ 个物理位姿（位置 + 姿态）
4. 调整 URDF 变换以最小化 RMS 误差
5. **验收**：位置误差 < 阈值，姿态误差已记录

**阶段 3：主从坐标变换**
1. 建立 `uarm_base` 与 `dummy_base` 坐标系
2. 推导旋转矩阵 A：uarm_base → dummy_base
3. 独立测试平移轴（5mm 增量）
4. 独立测试旋转轴（5° 增量）
5. **验收**：主空间运动可预测地映射到从空间

**阶段 4：缩放与死区标定**
- 平移缩放：0.30（初始，可调）
- 旋转缩放：0.50（初始，可调）
- 死区：0.5° 当量（噪声抑制）
- 速度限制：0.05 m/s 平移、0.5 rad/s 旋转
- 加速度限制：0.20 m/s²、2.0 rad/s²

**触发/夹持器标定：**
- 将伺服角度映射到夹持器比率 [0.0, 1.0]
- 参数：`zero_deg`、`minimum_travel_deg`、`deadband_ratio`
- 处理 360° 环绕
- 输出限幅，死区移除后重新缩放
- 映射到夹持器关节：open=0.044、closed=0.0

| 风险 | 影响 | 证据 | 缓解措施 |
