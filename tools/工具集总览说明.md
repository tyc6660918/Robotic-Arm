# 工具集总览

## 1. 区域用途

`tools/` 目录为外科手术机器人训练平台提供完整的开发与验证工具链。其包含四个主要子系统：（1）用于实时机器人控制与参数整定的串口通信接口；（2）用于运动学验证的三维可视化工具；（3）具备完整控制回路建模的离线数字孪生仿真环境；以及（4）硬件调试基础设施。这些工具使得固件开发、算法验证和系统集成测试无需持续访问物理硬件即可进行。

## 4. 已完成功能

### 串口通信与控制（`tools/simple-cli/`）

**simple-cli.py**：功能完整的 ASCII 协议命令行工具，支持自动端口检测（优先 COM5/COM6，然后 VID/PID 扫描）。命令包括 enable/disable/stop、home、move（6 关节）、movej（单关节）、status/jpos/lpos、PID 整定（kp/ki/kd、模式切换、重启）、以及用于协议检查的调试开关。SKIP_PORTS 过滤 COM3、COM4、蓝牙端口。

**streaming_control.py**：实时 50Hz 键盘点动控制，支持双模式操作：
- JOINT 模式：Q/A=J1、W/S=J2、E/D=J3、R/F=J4、T/G=J5、Y/H=J6
- CARTESIAN 模式：Q/E=X、A/D=Y、W/S=Z、R/F=A、T/G=B、Y/H=C
- 聚焦作用域输入：仅当控制台在按键按下时获得焦点 AND 物理按键仍按下时才识别按键
- 响应消费：每个 '>' / '@' 绘制 FIFO 槽计数 + 'ok'，未读字节会阻塞 USB 发送
- 背压跟踪：监控 queue_free（0..15），检测丢弃（0xFF = FIFO 已满）
- 速度控制：1-0 键用于预设速度，[ / ] 键用于 ±30% 调整，支持速度或步进模式
- 安全：有界写入超时（0.01s），SerialException 时设置 link_lost 标志
- Windows 定时器：使用 `timeBeginPeriod(1)` 实现 1ms 精度

**dummy_port_scanner.py**：基于硬件 ID 的检测，目标为 CP2102（VID=10C4，PID=EA60，UART4 路径）和 STM32 CDC（VID=0483，PID=5740，内置 USB）。使用 #GETJPOS 探测验证，期望返回 'ok' + 6 个浮点数。

**test_streaming_control.py**：协议模拟器，FakeController 实现 16 槽 FIFO，返回空闲计数或满时返回 0xFF。测试覆盖响应消费、队列跟踪、分割行、写入超时、启动顺序。KeyboardMonitor 覆盖聚焦作用域、边缘检测、锁存清除。

### 三维可视化（`tools/robot-viewer/`）

**robot_viewer.py**：matplotlib 三维骨架查看器，支持实时模式（15Hz 关节查询、正向运动学计算、8 面厚管渲染）和离线模式（使用 REST_ANGLES [0, -73, 180, 0, 0, 0]）。管道按连杆颜色编码，半径从 18mm 渐缩至 6mm。标记包括黄色关节、红色末端执行器（100pt）、白色基座（60pt 方形）。在标题栏显示末端执行器位置和关节角度。

**fk_solver.py**：URDF 提取的 DH 参数，JOINT_DEFS 包含（name, parent_idx, origin_xyz, axis_xyz, visual_offset_xyz）× 6。每关节返回（local_pos, local_euler_deg, visual_offset）。

### 离线仿真（`tools/windows_sim/`）

**run_sim.py**：完整遥操作控制回路（1237 行），支持 Dummy 6 自由度和 OpenRST 4 自由度（pitch/yaw/grasp）。特性包括：
- 运动学：有界逆运动学求解器，max_nfev=15，成功时重新播种
- 滤波：位置与姿态的 One-Euro 滤波器，可配置 min_cutoff/beta/derivative_cutoff
- 速率限制：线速度/角速度与加速度约束
- 安全：TeleopState 状态机、输入超时、跟踪误差监控（最大 0.12 rad，0.5s 宽限）、失速检测
- 对象：MockJointPlant，具备加加速度受限动力学、命令延迟、丢包、反馈噪声
- 模式：实时（线程化 50Hz）或快速（run_fast 用于批量场景）
- 场景：JSON 驱动的参数化或脚本化执行，含震颤频谱分析
- 输出：CSV 遥测与综合指标 JSON 报告

**validate_kinematics.py**：FK→IK→FK 往返测试，生成 1000 个随体位姿（固定种子），跳过奇异构型（SVD < 1e-4）。验收标准：success_rate ≥ 99%、位置误差 < 0.1mm、姿态误差 < 0.05°。报告求解时间 p50/p99 及失败示例。

### 调试与烧录（`debug/openocd-configs/`）

**test-connection.sh**：通过测试 stlink-f103、stlink-f405、cmsis-dap-f103、wch-link-f103 自动检测可用调试器配置。以 3 秒超时验证，grep "Listening on port"，将可用配置输出到 /tmp 并附使用示例。

**配置文件**：SWD 传输配置，含 reset_config 和适配器速度设置：
- stlink-f103：target/stm32f1x.cfg
- cmsis-dap-f103：adapter cmsis-dap + f1x
- wch-link-f103：WCH RISC-V JTAG 适配器（STM32 兼容模式）

### IoT 桥接（`tools/esp32-iot/`）

ESP32 的 Mongoose OS 示例（UART 桥接、设备仪表盘）。构建流程：`make build` → `esputil mkhex` → 烧录。分区表 @ 0x8000，引导加载器 @ 0x1000，应用 @ 0x100000。烧录参数：`-fspi 6,17,8,11,16`（SPI 引脚）。

## 6. 使用说明

### 串口通信工具

**自动端口检测**：
```bash
python tools/simple-cli/dummy_port_scanner.py
```
扫描 CP2102（VID:10C4 PID:EA60）和 STM32 CDC（VID:0483 PID:5740），使用 #GETJPOS 探测验证。

**交互控制**：
```bash
python tools/simple-cli/simple-cli.py
```
命令：
- `enable` / `disable` / `stop`：电机控制
- `home`：返回零位
- `move J1 J2 J3 J4 J5 J6`：移动全部关节（角度）
- `movej <joint_num> <angle>`：移动单关节
- `status` / `jpos` / `lpos`：查询机器人状态
- `kp <joint> <value>` / `ki` / `kd`：PID 整定
- `mode <1|2>`：CMDMODE 1（阻塞），2（非阻塞队列）
- `reboot`：重启控制器
- `debug`：切换协议检查

**实时键盘点动**：
```bash
python tools/simple-cli/streaming_control.py
```
控制（50Hz 更新率）：
- **JOINT 模式**：Q/A=J1、W/S=J2、E/D=J3、R/F=J4、T/G=J5、Y/H=J6
- **CARTESIAN 模式**：Q/E=X、A/D=Y、W/S=Z、R/F=A、T/G=B、Y/H=C
- **速度**：1-0 键预设速度，[ 减 30%，] 加 30%
- **模式切换**：M 键切换 JOINT/CARTESIAN
- **安全**：ESC 紧急停止

输入需要控制台焦点。监控 FIFO 背压（0..15 空闲槽），满时（0xFF）丢弃命令。

### 三维可视化

**实时渲染**（15Hz）：
```bash
python tools/robot-viewer/robot_viewer.py
```
通过串口连接控制器，读取关节角度，显示带厚管和末端执行器位置的正向运动学骨架。

**离线演示**：
```bash
python tools/robot-viewer/robot_viewer.py --no-connect
```
使用 REST_ANGLES [0, -73, 180, 0, 0, 0] 进行静态位姿可视化。

### Windows 仿真

**运动学验证**：
```bash
python tools/windows_sim/validate_kinematics.py
```
生成 1000 个随体位姿，求解逆运动学，测量 FK→IK→FK 往返误差。输出 JSON 报告，包含成功率、位置/姿态误差统计、求解时间百分位数。

验收标准：
- 成功率 ≥ 99%
- 位置误差 < 0.1mm
- 姿态误差 < 0.05°

**遥操作仿真**（实时模式）：
```bash
python tools/windows_sim/run_sim.py --mode realtime --gui
```
运行 50Hz 控制回路，配合 One-Euro 滤波、速率限制、安全状态机。GUI 显示关节状态、跟踪误差、控制信号。

**批量场景执行**（快速模式）：
```bash
python tools/windows_sim/run_sim.py --mode fast --scenario <scenario.json>
```
以最高速度运行参数化或脚本化场景。输出 CSV 遥测与指标 JSON 报告（逆运动学成功率、位置 RMS、控制量）。

**震颤频谱分析**：
```bash
python tools/windows_sim/run_sim.py --analyze-tremor --freq-range 4-12
```
验证 One-Euro 滤波器在衰减生理性震颤（4-12 Hz）方面的有效性。

### 协议说明

**ASCII 命令**：
- `#` 前缀用于查询（如 `#GETJPOS`、`#GETMPU`）
- `!` 前缀用于控制（如 `!ENABLE`、`!DISABLE`）
- `>` 前缀用于关节运动（如 `>J1 90`）
- `@` 前缀用于笛卡尔运动（如 `@X 100 Y 50 Z 200`）

**响应**：
- 成功返回 `ok <data>`
- 非阻塞模式下运动命令返回空闲槽计数（0..15）或 0xFF
- 错误码（待确认）

**模式**：
- CMDMODE 1：阻塞（等待运动完成）
- CMDMODE 2：非阻塞（16 槽 FIFO 队列）

**关节限位**（角度）：
- J1：[-170, 170]
- J2：[-73, 90]
- J3：[35, 180]
- J4：[-180, 180]
- J5：[-120, 120]
- J6：[-720, 720]

## 7. 风险与局限

| 风险 | 影响 | 证据 | 缓解措施 |
|------|--------|----------|------------|
| URDF 路径不匹配导致仿真中断 | 高 | 仿真代码引用不存在的 'Moveit_ws-main' 而非 'moveit2_ws'。多个文档文件引用已删除的 'rst-control-fw' 路径 | 通过查找替换优先修复。预计 30 分钟。在仿真启动时添加路径验证 |
| USB 串口背压导致命令丢失 | 中 | `streaming_control.py` 跟踪 FIFO（0..15 槽）但未读响应会阻塞 USB 发送缓冲。控制器满时返回 0xFF | 已实现响应消费（每次 '>' / '@' 后读取）。监控 `queue_free` 指标。考虑流控或更大 FIFO |
| Windows 定时器精度影响控制回路时序 | 中 | `streaming_control.py` 使用 `timeBeginPeriod(1)` 实现 1ms 精度，但 Windows 调度仍有约 15ms 抖动 | 已记录为局限。替代方案：生产环境使用高精度多媒体定时器或 Linux 实时内核 |
| 聚焦作用域键盘在窗口切换期间可能丢失输入 | 低 | KeyboardMonitor 仅识别控制台窗口获得焦点时按下的按键 | 已记录行为。用户培训：点动期间保持控制台聚焦。考虑为紧急停止注册全局热键 |
| 仿真未建模 RST 夹持器中的绳索拉伸 | 中 | `windows_sim/run_sim.py` 使用 IdealOpenRSTModel 实现对称抓取，省略绳索动力学、摩擦、滞回 | 已确认局限。真实硬件可能需要大量整定。计划包含模型细化的硬件验证阶段 |
