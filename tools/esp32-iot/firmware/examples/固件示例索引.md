# Mongoose 网络协议库固件示例索引

若需构建并运行任一现有示例，请参阅：
https://mongoose.ws/documentation/#how-to-build-and-run-examples

## 示例贡献规范

创建新示例的规则：

- 桌面/服务器类示例的 Makefile 黄金参考：[http-server](http-server)
- 嵌入式示例的 Makefile 黄金参考：[stm32/nucleo-f746zg-baremetal](stm32/nucleo-f746zg-baremetal)
- 示例必须能在 Windows、Mac 与 Ubuntu Linux 系统上构建通过
- 假定用户已按照 https://mongoose.ws/tutorials/tools/ 中的说明安装好工具链
- Makefile 不得包含任何其他 make 文件
- 系统特定的编译选项使用 `CFLAGS`
- Mongoose 特定的编译选项使用 `CFLAGS_MONGOOSE`
- 编译时应使用 `$(CFLAGS) $(CFLAGS_MONGOOSE) $(CFLAGS_EXTRA)`
- 若需要外部仓库，通过 git 浅克隆按需下载。请参阅嵌入式示例黄金参考
- Makefile 应尽可能简洁，但需足够清晰以便理解
- 如需使用 `mongoose.c`、`ca.pem` 等文件时，请使用符号链接，请勿复制
- 示例的 README.md 应仅包含标题与指向 mongoose.ws 教程页面的链接
