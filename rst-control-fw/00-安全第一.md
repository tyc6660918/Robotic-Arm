# ⚠️ 安全第一 - 防止烧板指南

## 🛡️ 在开始之前，请务必阅读

### 什么情况会烧板？
1. **电源反接** - 正负极接反
2. **短路** - 裸露线头碰到一起
3. **过压** - 12V 接到 3.3V/5V 引脚
4. **电机堵转过载** - 电流过大烧驱动板
5. **热插拔通电设备** - 带电插拔

### 什么情况不会烧板？
✅ 只接 DAP 下载器（安全）
✅ 只接 CH340 串口（安全）
✅ 只用 USB 供电测试（安全）
✅ 先断电再接线（安全）
✅ 不接电机驱动（安全）

## 🚫 安全规则（必须遵守）

### 接线规则
1. ✅ **断电操作** - 所有接线都在断电状态下进行
2. ✅ **先检查后通电** - 接完线用万用表测一下，没问题再上电
3. ✅ **从简到繁** - 先测试 MCU，再测试电机
4. ✅ **小功率测试** - 电机测试从 PWM=50 开始，慢慢加
5. ✅ **准备断电** - 手放在电源开关上，随时能断电

### 禁止操作
1. ❌ **不要热插拔** - 通电时不要插拔任何线
2. ❌ **不要带电接线** - 接线时必须断电
3. ❌ **不要接错引脚** - 12V 不能接到 3.3V/5V 引脚
4. ❌ **不要短路** - 裸露线头用热缩管包好
5. ❌ **不要满载启动** - 电机测试先空载

## 📸 建议准备

1. **拍照记录** - 每次接线都拍照，方便检查
2. **标签纸** - 给线做标记（红=12V，黑=GND，黄=信号）
3. **万用表** - 测电压，防止接错
4. **紧急断电** - 桌上放个独立电源开关

## 🔌 接线步骤（阶段 1）

### ⚠️ 重要：全程断电操作

### 第 1 步：断开所有电源
```
□ 拔掉野火板的 USB 线
□ 拔掉 DAP 的 USB 线
□ 拔掉 CH340 的 USB 线
```

### 第 2 步：连接 DAP 下载器

野火板上找到 **SWD 接口**（通常是 4pin 或 5pin 排针，标注：SWDIO, SWCLK, GND, 3.3V）

| DAP 引脚 | 野火板 SWD | 杜邦线颜色建议 |
|---------|-----------|--------------|
| SWDIO | SWDIO | 蓝色 |
| SWCLK | SWCLK | 绿色 |
| GND | GND | 黑色 |
| 3.3V | 不接 | - |

**检查清单：**
```
□ SWDIO 对 SWDIO
□ SWCLK 对 SWCLK
□ GND 对 GND
□ 没有线悬空或碰到其他引脚
□ 拍照记录
```

### 第 3 步：连接 CH340 串口

野火板上找到 **USART1 接口**（标注：PA9=TX1, PA10=RX1, GND）

| CH340 引脚 | 野火板引脚 | 杜邦线颜色建议 | 注意 |
|-----------|-----------|--------------|------|
| TXD | PA10 (RX1) | 黄色 | 交叉连接 |
| RXD | PA9 (TX1) | 橙色 | 交叉连接 |
| GND | GND | 黑色 | - |
| VCC | 不接 | - | CH340 自带 USB 供电 |

**检查清单：**
```
□ CH340 的 TXD 接 PA10（交叉）
□ CH340 的 RXD 接 PA9（交叉）
□ GND 对 GND
□ VCC 不接
□ 没有接错到其他引脚
□ 拍照记录
```

### 第 4 步：最终检查

**用万用表测试（可选但推荐）：**
```
□ DAP 的 GND 和野火板 GND 导通
□ CH340 的 GND 和野火板 GND 导通
□ 没有意外短路（万用表蜂鸣档测任意两个信号线，不应该响）
```

**目视检查：**
```
□ 所有线插牢固
□ 没有裸露线头碰到一起
□ 没有线悬空
□ 拍照存档
```

### 第 5 步：上电（按顺序）

1. **先接 USB 线到野火板**（板子通电，LED 应该亮）
2. **再接 USB 线到 DAP**（连接电脑）
3. **最后接 USB 线到 CH340**（连接电脑）
