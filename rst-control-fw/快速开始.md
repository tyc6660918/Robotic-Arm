# 快速开始 - 第一次测试

## 🎯 目标
先让系统跑起来，能通过串口通信。**暂时不接电机**。

---

## 第一步：最小接线（5分钟）

### 你需要接的线：

#### 1. ST-Link（烧录器）
```
ST-Link          野火霸道板
SWDIO    ─────→  PA13 (SWD接口)
SWCLK    ─────→  PA14 (SWD接口)
GND      ─────→  GND
```
💡 野火板上有 SWD 接口，直接插 ST-Link 即可

#### 2. USB 线（供电 + 串口）
```
电脑 USB  ─────→  野火板 USB 接口
```
💡 野火板自带 CH340 串口芯片，一根 USB 线搞定供电和调试

#### 3. 就这些！
- ❌ 不接电机
- ❌ 不接驱动板
- ❌ 不接编码器
- ❌ 不接 12V 电源

## 第二步：在 CubeMX 中配置（10分钟）

### 1. 打开项目
```
双击: rst-control-fw/rst-control-fw.ioc
```

### 2. 配置 TIM6（必须！）
- 左侧 **Timers** → **TIM6**
- 勾选 `Activated`
- **Configuration** → **Parameter Settings**:
  - Prescaler: `35`
  - Counter Period: `99`
- **NVIC Settings**:
  - 勾选 `TIM6 global interrupt`
  - Priority: `0`

### 3. 配置 ADC1 + DMA（必须！）
- 左侧 **Analog** → **ADC1**
- **Mode**:
  - IN3: `ADC1_IN3`
  - IN4: `ADC1_IN4`
  - IN5: `ADC1_IN5`
- **Configuration** → **Parameter Settings**:
  - Scan Conversion Mode: `Enable`
  - Continuous Conversion: `Enable`
  - DMA Continuous Requests: `Enable`
  - Number of Conversion: `3`
- **DMA Settings** → **Add**:
  - DMA Request: `ADC1`
  - Mode: `Circular`
  - Data Width: `Half Word` (两个都选)

### 4. 生成代码
```
点击右上角 [GENERATE CODE] 按钮
```

## 第三步：在 Keil 中编译（5分钟）

### 1. 打开项目
```
双击: rst-control-fw/MDK-ARM/rst-control-fw.uvprojx
```

### 2. 添加新文件
- 左侧 **Project** 窗口
- 右键 `Application/User/Core` → `Add Existing Files to Group`
- 选择：
  - `Core/Src/control_loop.c` ✅
  - `Core/Src/tim6.c` ✅

### 3. 编译
```
按 F7 或点击 Build 图标
```

应该看到：
```
0 Error(s), 0 Warning(s)
```

---

## 第四步：烧录固件（2分钟）

### 1. 连接 ST-Link
- ST-Link 插入电脑 USB
- ST-Link 另一端连接野火板 SWD 接口

### 2. 下载
```
Keil 中按 F8 或点击 Download 图标
```

应该看到：
```
Programming Done
Verify OK
```

---

## 第五步：打开串口测试（2分钟）

### 1. 找到串口号
- 打开 **设备管理器**
- **端口(COM 和 LPT)**
- 找到 `USB-SERIAL CH340 (COMx)`
- 记住端口号，比如 `COM3`

### 2. 打开串口工具
推荐用：
- **SSCOM** (串口调试助手)
- **MobaXterm**
- **Tera Term**
- **PuTTY**

### 3. 串口设置
```
端口：COM3 (你的实际端口)
波特率：115200
数据位：8
停止位：1
校验：None
```

### 4. 连接
点击 **打开串口** 或 **Connect**

## ❌ 如果出错

### 编译错误
| 错误信息 | 原因 | 解决 |
|---------|------|------|
| `undefined reference to TIM6_IRQHandler` | CubeMX 未配置 TIM6 | 回到第二步重新配置 |
| `cannot open source file "control_loop.c"` | Keil 未添加文件 | 回到第三步添加文件 |

### 烧录错误
| 错误信息 | 原因 | 解决 |
|---------|------|------|
| `No Target Connected` | ST-Link 未连接 | 检查 SWD 接线 |
| `Flash Download failed` | 芯片保护 | Keil → Flash → Erase Full Chip |

### 串口错误
| 现象 | 原因 | 解决 |
|------|------|------|
| 找不到 COM 口 | 驱动未安装 | 安装 CH340 驱动 |
| 打开失败 | 端口被占用 | 关闭其他串口工具 |
| 乱码 | 波特率错误 | 确认波特率 115200 |
| 无输出 | 未复位 | 按板上 RESET 按钮 |
