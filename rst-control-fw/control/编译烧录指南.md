## 📋 第一步：打开 Keil 项目

1. **打开项目文件**
   ```
   双击：E:\Robotic-Arm\rst-control-fw\control\MDK-ARM\control.uvprojx
   ```

2. **等待 Keil 加载**（10-20秒）

---

## 🔧 第二步：配置下载器

1. **点击工具栏的 "魔术棒" 图标**（Options for Target）

2. **切换到 Debug 选项卡**
   - Use: 下拉选择 `CMSIS-DAP Debugger`
   - 点右侧 `Settings` 按钮

3. **在 Settings 窗口 - Debug 选项卡**
   - Port: 选择 `SW`
   - Max Clock: `10 MHz`（默认即可）

4. **切换到 Flash Download 选项卡**
   - 勾选 `Reset and Run`
   - Programming Algorithm: 应该自动有 `STM32F10x High-density Flash`

5. **点击 OK → OK**

---

## 🔨 第三步：编译

1. **点击工具栏 "Build" 图标**（或按 F7）

2. **等待编译完成**（20-30秒）

3. **检查编译结果**
   - Build Output 窗口应该显示：
     ```
     compiling main.c...
     compiling control_loop.c...
     compiling tim6.c...
     compiling debug_console.c...
     ...
     linking...
     Program Size: Code=xxx Data=xxx
     "control.axf" - 0 Error(s), 0 Warning(s).
     ```

### ⚠️ 如果有编译错误

**常见错误 1：找不到头文件**
```
Error: cannot open source input file "rst_config.h"
```
**解决：** 检查 `Core/Inc/rst_config.h` 是否存在

**常见错误 2：未定义的函数**
```
Error: undefined symbol RST_StartControlLoop
```
**解决：** 检查 `Core/Src/control_loop.c` 是否存在

**如果遇到其他错误，截图发给我！**

## 可能的结果：

### ✅ 成功（最好的情况）
```
Load "E:\...\control.axf"
Set JLink Project File to "..."
Erase Done.
Programming Done.
Verify OK.
Application running ...
```
**太好了！继续下一步串口测试！**

---

### ❌ 找不到 DAP
```
Error: No CMSIS-DAP device found
或
Error: Flash Download failed - Target DLL has been cancelled
```

**解决方法：**

1. **检查 DAP 连接**
   - 重新插拔 DAP USB
   - 确认 DAP 上的 LED 亮
   - 检查 SWD 4根线是否插紧

2. **安装 DAP 驱动（用 Zadig）**
   ```
   下载：https://zadig.akeo.ie/
   运行 zadig.exe
   菜单：Options → List All Devices
   找到：CMSIS-DAP 或类似设备
   驱动选择：WinUSB
   点击：Install Driver 或 Replace Driver
   等待完成后重新插拔 DAP
   ```

3. **再次尝试烧录**

---

### ❌ 连接失败
```
Could not stop Cortex-M device!
或
SWD/JTAG Communication Failure
```

**解决方法：**

1. **检查 SWD 接线**
   ```
   DAP        野火板 SWD
   SWDIO  →  SWDIO
   SWCLK  →  SWCLK  
   GND    →  GND
   3.3V   →  3.3V（可选）
   ```

2. **降低时钟速度**
   - Options → Debug → Settings
   - Max Clock: 改为 `1 MHz` 或 `2 MHz`
   - 重试

3. **按住野火板复位键，点击下载，然后松开复位键**

---

## 📡 第五步：串口测试

### 烧录成功后：

1. **打开串口工具**
   - 推荐：PuTTY, Tera Term, 或 串口调试助手
   
2. **配置串口**
   ```
   端口：COM9（你的 CH340 端口）
   波特率：115200
   数据位：8
   停止位：1
   校验：None
   ```

3. **打开串口**

4. **应该看到启动信息**
   ```
   === RST Control Firmware ===
   Build: Aug  9 2026 04:15:32
   Control loop started at 20kHz
   Type 'help' for commands
   ```

5. **输入命令测试**
   ```
   help     ← 回车
   info     ← 回车（应该看到 Loop Cnt 在增加）
   ```
