# RST 三轴机械臂控制器 - 完整接线教程

## 硬件清单

### 必需硬件
- ✅ 野火霸道开发板（STM32F103ZET6）
- ✅ WHEELTEC 直流电机 × 3（带编码器 GMR）
- ✅ TB6612 双路电机驱动模块 × 2（或 TB6612FNG 驱动板）
- ✅ USB-UART 转换器（CP2102 或 CH340）
- ✅ ST-Link V2 下载器
- ✅ 12V 电源（推荐 3A 以上）
- ✅ 杜邦线若干

### 可选硬件
- 🔧 INA180A1 电流检测模块 × 3
- 🔧 4 位拨码开关（设置 CAN ID）
- 🔧 按键 × 2
- 🔧 LED × 4

---

## 📌 第一部分：基础测试接线（最小系统）

### 目标
先让系统跑起来，能通过串口调试。**不接电机**，只测试 MCU 和串口通信。

---

## 1. ST-Link 连接（烧录器）

| ST-Link 引脚 | STM32F103ZET6 引脚 | 说明 |
|-------------|-------------------|------|
| SWDIO | PA13 | 数据线 |
| SWCLK | PA14 | 时钟线 |
| GND | GND | 地 |
| 3.3V | 3.3V | 供电（可选） |

⚠️ **注意**：
- 野火霸道板上通常有 SWD 接口，直接插 ST-Link 即可
- 如果板子有独立供电，ST-Link 的 3.3V 可以不接

---

## 2. USB-UART 串口连接（调试控制台）

| USB-UART | STM32 引脚 | 说明 |
|----------|-----------|------|
| TXD | PA10 (USART1_RX) | 交叉连接 |
| RXD | PA9 (USART1_TX) | 交叉连接 |
| GND | GND | 地 |

⚠️ **注意**：
- TX 接 RX，RX 接 TX（交叉连接）
- 野火板上通常有 CH340 USB 转串口芯片，可以直接用 USB 连接电脑
- 如果板载串口，可以不用外接 USB-UART

---

## 3. 供电

### 方式 1：USB 供电（测试用）
- 野火板通过 USB 线连接电脑
- 仅供 MCU 工作，**不能带电机**

### 方式 2：外部电源（实际使用）
- 12V DC 电源接入板子的电源接口
- 注意**正负极**

## 📌 第二部分：完整接线（含电机驱动）

### 系统拓扑
```
[12V 电源]
    ├─→ [STM32 开发板] ─→ [ST-Link 下载]
    │       ├─→ [USB-UART 调试]
    │       └─→ [GPIO 控制]
    │               ↓
    └─→ [TB6612 驱动 #1] ─→ [电机 0: Pitch]
    │       ├─→ [电机 1: 上夹]
    │       └─→ [编码器接 STM32]
    │
    └─→ [TB6612 驱动 #2] ─→ [电机 2: 下夹]
            └─→ [编码器接 STM32]
```

## 4. TB6612 电机驱动连接

| TB6612 引脚 | 接线 | 说明 |

|------------|-----------|------|
| BIN1 | PB5 | 方向控制 1 |
| BIN2 | PB12 | 方向控制 2 |

| TB6612 引脚 | 接线 | 说明 |

|------------|-----------|------|

## 📌 第三部分：接线检查清单

### 烧录前检查
- [ ] ST-Link 连接正确（SWDIO, SWCLK, GND）
- [ ] USB-UART 连接正确（TX↔RX 交叉）
- [ ] 野火板供电正常（USB 或 12V 外部电源）

### 电机驱动检查
- [ ] TB6612 电源正确（VM=12V, VCC=5V, GND 公共）
- [ ] PWM 信号线连接（PA8, PC6, PC7）
- [ ] 方向控制线连接（PB0/1, PB5/12, PB13/14）
- [ ] STBY 引脚接 5V（使能驱动）

### 编码器检查
- [ ] 编码器 A/B 相连接正确
- [ ] 编码器供电正确（5V 和 GND）
- [ ] PA15/PB3 引脚功能正确（需要在 CubeMX 中配置）

### 电机检查
- [ ] 电机相线连接牢固（红/黑线）
- [ ] 电机没有卡死，可以手动转动
- [ ] 三个电机对应关系正确（Pitch=TIM3, 上夹=TIM4, 下夹=TIM2）

## 📌 第四部分：分步测试流程

### 阶段 1：MCU 基础测试（不接电机）
```
目标：验证 MCU 和串口通信正常
接线：仅 ST-Link + USB-UART
测试：烧录固件，打开串口，输入 help
```

### 阶段 2：编码器测试（不接驱动）
```
目标：验证编码器读取正常
接线：+ 编码器信号线
测试：串口输入 enc 0, enc 1, enc 2，手动转电机看计数
```

### 阶段 3：驱动板测试（空载）
```
目标：验证 PWM 输出和方向控制
接线：+ TB6612 控制信号（不接电机）
测试：串口输入 pwm 0 100，用示波器测 PA8 输出
```

### 阶段 4：电机测试（负载）
```
目标：电机低速转动
接线：+ 电机相线
测试：串口输入 pwm 0 50，观察电机缓慢转动
```

### 阶段 5：完整系统测试
```
目标：闭环控制
接线：全部接完
测试：位置模式、速度模式、力矩模式
```

## ⚠️ 安全警告

### 接线时
1. **断电操作**：接线时必须断电
2. **检查极性**：12V 电源正负极，LED 正负极
3. **防短路**：裸露的线头用热缩管包好

### 首次上电
1. **检查发热**：上电后立即摸 TB6612，不应烫手
2. **检查电压**：万用表测量 5V 和 12V 是否正常
3. **准备断电**：手放在电源开关上，随时断电

### 电机测试
1. **从小到大**：PWM 从 50 开始，逐步增加
2. **空载测试**：先不装机械臂，电机空转测试
3. **观察电流**：电流超过 2A 立即停止
